El editor permite escribir fórmulas con dos propósitos: representación visual/impresión y análisis/cálculo de cálculos matemáticos. Se pueden usar fórmulas que se puedan calcular o resolver, con fórmulas solo para exportación (LaTeX, imagen, etc.), incluyendo texto normal. Las fórmulas pueden ser definiciones de variables y funciones, y referenciarse entre sí, lo que permite escribir programas sencillos que realicen cálculos numéricos.

El editor está disponible comoaplicación de Android y aplicación web.

Edición básica

Tenga en cuenta que en muchos casos el editor no solo inserta un nuevo símbolo sino que también corrige lo que ha escrito antes.

AAl escribir, muchos botones del panel principal cambian. Al presionar un botón repetidamente, se puede ajustar lo que se insertó anteriormente. Por ejemplo, al presionar un botón de fracción se incluirán más términos en el numerador. Para otros botones, simplemente verifique cómo cambian después de presionarlos una vez.

A medida que escribes, aparecen muchos botones adicionales a la izquierda y a la derecha de la pantalla. Se llamanbotones de contextoPor ejemplo, al escribir una letra, aparece la lista de funciones que empiezan con esa letra. También puedes seleccionar cualquier elemento.y Los botones pueden aparecercambiar él.

Para escribir una letra mayúscula, mantenga presionada una tecla.

Entre todas las fórmulas que escribe, el editor busca símbolos que sean difíciles de volver a escribir: se agregan en la parte inferior derecha para un acceso rápido.

Uso de comandos de látex

Escriba el nombre completo de un símbolo (comando) en LaTeX y aparecerá un botón para insertarlo.

Lista de símbolos y comandos admitidos.

Puede introducir cualquier símbolo escribiendo su número hexadecimal Unicode. Por ejemplo, si escribe "2295", aparecerá el botón contextual con el símbolo ⊕. También puede combinar dos símbolos, por ejemplo, escriba u303. Primero, pulse el botón con tilde (código 303); a continuación, aparecerá un botón con el símbolo ũ, que combina u y tilde.

Exportación/Importación

Puede exportar fórmulas en varios formatos.

  • Látex

Formato LaTeX conocido para la representación visual y la impresión de fórmulas de alta calidad. Sin embargo, no es fiable si se desea restaurar fórmulas, ya que no está diseñado para preservar su significado exacto.

  • Texto de fórmulas (formato de texto corto)

El formato de texto representa el significado matemático de la fórmula de forma breve (pero no su aspecto). Es probable que muchas otras aplicaciones lo reconozcan para tipos comunes de fórmulas. Coincide con el lenguaje de Matlab en muchos aspectos, pero no siempre. Es posible que parte del texto que escriba no se pueda convertir a este formato. Puede contener símbolos Unicode (no ASCII) al usarlos.

  • Datos completos (json)

Le permitirá restaurar todas sus fórmulas tal como las ve, incluyendo algunos datos adicionales. Solo se puede usar con este editor. No es muy adecuado para la visualización/edición manual. Se basa en formato JSON. En Android, los archivos (*.json) se pueden abrir desde otras aplicaciones (se importarán).

  • PDF, Imagen (png)

Tenga en cuenta que las fórmulas pueden verse un poco diferentes a las de la aplicación. Durante la exportación, la calidad de la imagen se puede cambiar en la configuración. Durante la importación, la imagen se añade tal cual: no se reconocen las fórmulas.

En la aplicación web, también puede copiar la imagen de las fórmulas seleccionadas presionando Ctrl+Mayús+C. Para insertarla desde el portapapeles del sistema (copiada por otra aplicación), use Ctrl+Mayús+V. El formato de las fórmulas se determinará automáticamente; de ​​lo contrario, se insertará como un bloque de texto normal.

Diferencia entre Android y la aplicación web

La aplicación de Android generalmente tiene más funciones que la aplicación web.

Características de la aplicación de Android que no están presentes en la aplicación web:

  • cálculos numéricos con alta precisión cuando solo se utilizan operaciones aritméticas básicas
  • cálculo de algunas funciones especiales
  • Gráfico 3D
  • Fuente de usuario personalizada para comentarios

Solo la aplicación web tiene un modo diseñado para el uso del teclado físico (escritorio).

La aplicación web será más lenta y consumirá más batería en dispositivos móviles en comparación con la aplicación de Android.

Uso del teclado

Para un dispositivo Android puedes utilizar un teclado físico, así como también una aplicación web.

Al ejecutar la aplicación web en una computadora de escritorio o portátil, la interfaz de usuario se ajusta automáticamente al uso del teclado. Si realiza alguna acción sin el teclado, puede aparecer una nota en la parte superior de la pantalla con el atajo de teclado para esa acción.

La aplicación para Android permite activar el modo con teclado físico. Funcionará de forma similar a la aplicación de escritorio.

Puedes presionar un botón contextual (a la izquierda) presionando la barra espaciadora varias veces mientras mantienes presionada la tecla Ctrl. Puedes presionar un botón de sugerencias (a la derecha) presionando la barra espaciadora varias veces mientras mantienes presionadas las teclas Ctrl y Mayús. Lo mismo aplica para las letras escritas recientemente en la esquina inferior derecha (cuando no se muestran sugerencias).

Funciones

Si escribe unas cuantas letras seguidas de paréntesis no significará que se llama a la función.(aunque parece similar)Escriba la primera letra del nombre de la función o el nombre completo; aparecerá un botón de contexto.insertar la función llamar. Es posible que el editor no muestre los paréntesis en algunos casos, pero aparecen al colocar el cursor dentro o después de la función. Si desea que los paréntesis se muestren siempre, seleccione la función con argumento; aparecerá un botón contextual con la misma función configurada para que los paréntesis se muestren siempre.

No se puede editar el nombre de una función. Esto puede ser un inconveniente si la expresión del argumento es extensa. En ese caso, simplemente seleccione la función y verá que aparece un botón para copiar solo el argumento. Haga clic en él, escriba una nueva función y pegue el argumento.

Para usar sus propias funciones, simplemente escriba una letra seguida de paréntesis. Aparecerá un botón para reemplazarla con una llamada a una función que tendrá esa letra en su nombre. Para crear una función con un nombre más largo, seleccione algunas letras con paréntesis vacíos después. Tenga en cuenta que las funciones de una sola letra pueden mostrarse de forma diferente a las de varias..

Para definir una función, se crea una fórmula que tiene esta función llamada con argumentos de una sola letra, seguida de igual y una expresión que hace referencia a esos argumentos.

f(x)=x*x
f(x,y)=x*y

Dondequiera que utilice esa función, se puede calcular o reemplazar fácilmente por su definición si es necesario.

Arrastrar y soltar

Puedes cambiar fácilmente el orden de los multiplicadores o términos. Simplemente selecciona uno o más y arrastra la selección a una nueva ubicación. También funciona con fracciones: puedes mover elementos dentro y fuera de una fracción a otra. También funciona con ecuaciones con fracciones: puedes mover elementos del lado izquierdo de la ecuación al derecho y viceversa. El editor solo te permitirá realizar los movimientos que generalmente son matemáticamente correctos.

Cuando seleccionas una parte de la fórmula, es posible que veas un "YBotón "Extraer". Sirve para mayor comodidad y permite mover fácilmente la selección a una nueva fórmula que definirá una nueva variable. Simplemente escriba el nombre de la variable y se insertará en lugar de la selección. Esto permite dividir fácilmente fórmulas grandes en fórmulas más pequeñas, haciendo referencia entre sí mediante los nombres de las variables.

Añadiendo texto habitual

Puede insertar bloques de texto para usar variables con nombres largos o para escribir comentarios. El botón "Texto" le permite hacerlo. Aparece al crear una nueva fórmula (o escribes ‘t’.). Otro botón se encuentra debajo en el panel principal.

Se mostrará un cuadro de diálogo para editar texto y habrá una opción para elegir si ignorar este texto en matemáticas como comentario o procesarlo como variable.

Más tarde puedes hacer doble clic para editar el texto.

Cuando el texto sea grande, aparecerá un botón vertical a la derecha que le permitirá cambiar el ancho del bloque de texto.En la parte superior derecha del texto también hay un botón para cambiar la alineación.

Al escribir variables (la mayoría de los símbolos), cada una se asigna a bloques de texto separados; solo los dígitos se combinan automáticamente en un solo bloque: el número. El estilo cursiva se aplica a las variables de una sola letra de forma predeterminada, pero no a los bloques de texto más grandes.Cuando escribe (o selecciona) variossímbolosLuego también aparece un botón de contexto.Combínalos en un solo bloque de texto y se procesará como una sola variable con un nombre largo (si no hay espacios, etc.). Formato queLa cursiva o negrita se aplica a todo el bloque de texto.

En la configuración de la aplicación para Android, puedes cargar una fuente personalizada (desde https://fonts.google.com/) que se usará solo para comentarios. Esta opción no está disponible en todos los dispositivos, ya que requiere los servicios de Google.

Dibujo

El editor también permite dibujar e implementa numerosas funciones de un editor de gráficos vectoriales. Habilítelo en la configuración. Es posible dibujar cualquier forma, aplicar colores, cambiar los puntos de la forma, agrupar y cambiar el orden Z. Consulte las guías en video.

Análisis y transformación de expresiones

Cuando selecciona cualquier parte de la fórmula,el editorComenzará a buscar entre todas las fórmulas de la biblioteca integrada que se puedan aplicar a la expresión seleccionada. Enumerará todas las demás expresiones posibles que pueden seguir la original según las reglas matemáticas. También incluye soluciones a ejercicios matemáticos clásicos. Algunascomplejo cálculos Se iniciará solo después de seleccionar una expresión particular.

La lista de sugerencias puede ser muy larga, pero las mejores suelen aparecer entre las primeras. Cada sugerencia puede tener un botón que permite ver información más detallada sobre la fórmula de biblioteca utilizada.

Cuando el editor no puede encontrar una solución, hay un botón en la parte superior derecha para comenzar a buscar en Google.

Al hacer clicen Si se selecciona una sugerencia, se insertará de forma predeterminada reemplazando la expresión seleccionada. Aparecerá un botón que permite revertir la acción anterior, duplicar la fórmula original donde estaba la selección y luego realizar el reemplazo en la nueva fórmula, manteniendo la anterior. También se puede añadir la expresión sugerida a la seleccionada.después de los iguales firmar.

Seleccione una solavariable y el editor sugerirá más operaciones relacionadas con ella: sustitución, resolución de ecuación, etc. En este caso se transformará toda la fórmula.

Gráficos

Durante el cálculo o la creación de gráficos, el editor examina todas las fórmulas para ver cómo se relacionan entre sí. Por ejemplo:

r*c
r=sin(x)
c=cos(x)

Si hay definiciones duplicadas para una variable, se mostrará un signo de exclamación.

Para ver los gráficos, primero debe seleccionar las fórmulas que se incluirán. Al editar una fórmula, hay un botón a la izquierda para incluirla en los gráficos. Después de seleccionar al menos una fórmula, presione el botón en la esquina superior izquierda para mostrar los gráficos. Si esa fórmula tiene un signo igual, la expresión de la izquierda debe ser un nombre de variable simple o una función como f(x). Sin embargo, puede graficar cualquier desigualdad que produzca valores 0 o 1.

Tenga en cuenta que si selecciona una sola variable en una fórmula, el editor intentará resolver y generar la expresión para esa variable. También le permitirá...ver elgráficode lo producido función.

TEl editor comenzará a analizar todas las fórmulas que has incluido en el gráfico, de forma recursiva.escaneando a través detodas las fórmulas que definen las variables utilizadas en las fórmulas iniciales que ha incluido.

Al crear un gráfico habitual, el editor espera encontrar una variable sin fórmula. Esta se convertirá en una variable para el eje x. Otras variables para las que se deban definir valores numéricos se convertirán en parámetros.

Según la configuración, la variable "x" puede asumirse como predeterminada. Las demás variables se convertirán automáticamente en parámetros con sus valores predeterminados iniciales.

Cuando el gráfico esabiertoPara cada parámetro habrá un botón en la parte superior. Presiónelo para cambiar el valor del parámetro mediante un control deslizante. Hay dos botones que permiten cambiar el rango de valores del control deslizante. Si necesita establecer un valor exacto, configúrelo.en la fórmula para ese parámetro.

Gráficas de funciones con dos variables (funciones complejas)

El editor también permite analizar funciones con dos variables. Dibuja un tipo de gráfico coloreado que suele usarse para analizar funciones de números complejos (representados por dos números reales). Sin embargo, puede usarse para cualquier tipo de función con dos variables. Por ejemplo:

sin(x)+sin(y)

En este tipo de gráfico, el valor de la función se representa mediante colores. El rojo corresponde al valor máximo de la función y el azul al valor mínimo. Cada variable corresponde a cada eje.

Los valores mínimos y máximos se calculan solo dentro del área mostrada. Al cambiar de área, estos valores pueden cambiar significativamente, pero siempre habrá una distribución de color entre rojo y azul. La correspondencia entre el valor de la función y el color no es fija inicialmente. Es posible que primero deba...encontrar un áreaque produce valores mínimos y máximos adecuados (nosingularidad en ella), luego presione el botón superior derecho “Colores bloqueados” que fijará los colores recordando los valores mínimos y máximos actuales.

La distribución de color entre rojo y azul no siempre permite ver fácilmente cómo cambia la función. Existe un modo de ondas que permite dividir la onda roja y azul en varias. En este modo, el color ya no permite ver dónde está el mínimo o el máximo.

También existe un modo especial cuando se tienen dos funciones con dos variables. En este caso, una función principal definirá la distribución del color entre rojo y azul, como se explicó anteriormente. Otra función secundaria definirá el brillo desde el negro hasta el color más brillante. Puede configurar la función principal haciendo clic en ella en la esquina inferior izquierda.

Este modo está habilitado de forma predeterminada cuando tiene una función de número complejo.P.ej.

z=x+i*y
f=(z*z-2)/(1-2*i-z)

En los gráficos sólo debe incluirse la fórmula para “f”.En este caso la función principal será el argumento del número complejo calculado"F"El valor absoluto definirá el brillo. Hay un botón en la esquina superior derecha que permite activar o desactivar el cambio de brillo mediante la segunda función.

Botones quecerrar colores o cambiosyEl modo ondas se aplicará a la función principal actual. Si desea ajustar la distribución del brillo, debe configurar la segunda función como principal temporalmente. Después de ajustar la distribución del color a sus necesidades, vuelva a configurarla como secundaria.

Si desea graficar una función de argumento complejo,el El editor permite graficar solo esta función. Como solución alternativa,yPuedes ajustar la fórmula y convertir un número complejo en uno real (usando Re(z),Im(z),arg(z),|z|) y luego graficar cualquier número de dichas funciones.

Una superficie representada por funciones f(x,y) se llama superficie explícita.

Superficie paramétrica

Al graficar las ecuaciones x=…, y=…, z=…, se abre un gráfico 3D para una superficie paramétrica. El intervalo de cambio de cada variable (parámetro) siempre va de 0 a 1. Se pueden añadir fórmulas como u=2πu₁, en cuyo caso u₁ se convierte en variable y u pasa de 0 a 2π. Por ejemplo:

x=v*sin(u)
y=v*cos(u)
z=desde
v=3v₁
u=2πu₁

Las ecuaciones se pueden combinar en un sistema para mayor comodidad, especialmente en el caso de superficies múltiples.

Los nombres de los parámetros pueden ser diferentes: debe haber dos variables sin definición que se conviertan en parámetros. Sin embargo, no pueden ser x, y, z.

En el caso habitual hay dos parámetros (variables), en el caso de uno solo el gráfico se mostrará como un túnel en el espacio 3D.

Si desea graficar una superficie paramétrica, entonces cada función agregada a los gráficos debe ser una superficie paramétrica.

Creando mundos 3D

El editor te permite graficar múltiples superficies paramétricas, usar tus imágenes como texturas y cambiar muchos otros parámetros para diseñar mundos 3D interesantes con el poder de las matemáticas.

Una superficie simple se representa mediante un sistema de ecuaciones con las ecuaciones x=, y=, z=. Se pueden escribir varios sistemas en una sola fórmula mediante la operación de suma.

También puedes definir funciones y utilizarlas:

Solo se debe graficar la función superior. Cada función debe tener al menos un parámetro, incluso si no lo necesita.

Dentro del sistema puedes agregar varios parámetros como “resolution” arriba.

Tenga en cuenta que cada parámetro es un bloque de texto único y está marcado como nombre de variable (no como comentario).Escriba las dos primeras letras del nombre (dentro del sistema) y aparecerá el botón de contexto para insertarlo.

resolution

Define cuántos puntos se calcularán (resolución * resolución) y la suavidad de la superficie. También define en gran medida la memoria asignada y el tiempo de cálculo.Si tienes varias superficies, siempre debes intentar reducir ese parámetro lo máximo posible, manteniendo al mismo tiempo una apariencia aceptable.

Si el valor es 3 (mínimo permitido), entonces tendrá 9 puntos con valores de parámetros 0, 0,5, 1.

texture

Índice de la imagen en el lienzo. El índice 1 corresponderá a la imagen más grande (la más grande en cuanto al área real que ocupa en el lienzo; se puede ajustar fácilmente su tamaño). La imagen se dibujará para cubrir la superficie.

stretch

Define cuánto estirar la textura y qué tan grande se verá la textura (en ambas direcciones, conservando la relación de aspecto).

stretch2

Define estiramiento adicional en una sola dirección. Modifica la relación de aspecto de la textura.

stretchType

Valores 0 (predeterminado), 1, 2. Define el método para dibujar la textura. Si no se ve bien en algunas zonas, conviene probar otros métodos.

textureRotate

Valores 0 (predeterminado) o 1. El valor 1 hará que la textura gire 90 grados. Es como intercambiar los parámetros de superficie (u->v, v->u) en las fórmulas.

brightness

Valores fraccionarios de -1 a 1. El valor predeterminado es 0. Cambia el brillo de la superficie cuando se utiliza textura.

color

Un solo valor entero en formato RGB (rojo, verde, azul). 255 significa azul, 255*256 significa verde. Se recomienda usar la función "hex" y un valor hexadecimal, por ejemplo, hex(ff0000) significa rojo.

smooth

  • valor 0 - la superficie tendrá bordes distintos entre segmentos planos separados;
  • valor 1 (predeterminado): los bordes serán menos visibles excepto en caso de un gran cambio repentino de ángulo (como en el caso de un cubo);
  • Valor 2: todos los bordes son menos visibles, incluso el cubo se verá como otra cosa.

zOffset

Al tener varias superficies en un mismo lugar (muy superpuestas o coincidentes), se generará un conflicto sobre qué dibujar encima de otra. Puede haber fallos durante el dibujo. El valor -1 especifica que la superficie debe dibujarse encima. El valor 1 significa dibujar detrás. El valor predeterminado es 0. Puede usar otros valores fraccionarios para definir el orden, pero 1 o -1 suelen ser suficientes.

background

Valor 0 (predeterminado) o 1, lo que significa que la superficie forma parte del fondo: cielo, sol, luna (objetos lejanos). Durante la visualización de dicha superficie, la cámara siempre se ubica en el centro de coordenadas; cambiar de posición no modifica el aspecto de la superficie (su tamaño).

lines

Valor 0 o 1 (predeterminado). Configura el clima para mostrar las líneas de contorno sobre la superficie (cuando no hay textura).

Hay parámetros globales que se aplican a gráficos o juegos en 3D.

Puedes agregarlos al lienzo en cualquier lugar como una ecuación independiente.

P.ej.

positions

Define las posiciones iniciales permitidas del jugador y los objetos objetivo. El valor es un sistema de ecuaciones, similar al de una superficie 3D. Los objetos se distribuirán aleatoriamente a lo largo de la superficie.

size

Tamaño del jugador y los objetivos. Cuanto menor sea el tamaño, más grande parecerá el mundo.

El valor predeterminado es 1, lo que significa un tamaño predeterminado que depende del tamaño del mundo 3D. Un valor de 0,5 significa la mitad del tamaño predeterminado. Un valor demasiado bajo puede causar problemas con los gráficos.

Sistemas de ecuaciones

El editor puede resolver sistemas de ecuaciones lineales.

No está limitado a usar solo coeficientes numéricos. Si usa varias variables, el editor asumirá que el número de variables reales es igual al número de ecuaciones. El resto de las variables se considerarán parte de los coeficientes. Es posible que vea varias soluciones según las variables reales elegidas.Funciones como sin(x) también pueden considerarse como variables.

Puedes escribir un sistema en forma matricial y convertirlo a forma clásica y viceversa.

Al seleccionar un sistema, puede que aparezca un botón contextual con el mismo sistema, pero con una columna adicional con condiciones. Estos sistemas son útiles durante los cálculos. La condición en la última fila es opcional.

Matrices

Con matrices y vectores (en el caso particular de las matrices), el editor realizará la misma operación que con los números, excepto que en este caso no realiza cálculos numéricos, sino transformaciones de expresiones arbitrarias que producen una única matriz resultante. Si se define una variablecomo matrizTodas las demás fórmulas que la incluyan se calcularán como matrices. Sin embargo, en algunos casos, puede ser una matriz de una sola celda. El editor muestra el tamaño de la matriz calculada para cada fórmula.

Cálculo

Para utilizar differential (como dx), debe usar la función llamada "d" (escribir "d" seguido de "x" no se procesará como diferencial; el botón de contexto con la función aparece al escribir la letra "d"). Al escribir un argumento simple como "x", se mostrará simplemente como "dx". También puede escribir cualquier expresión. Al seleccionar la función...ción, el editor intentará encontrar una derivada para la expresión del argumento.

Integrales

Cuando escriba la letra “i” verá aparecer un botón de contexto integral.

La capacidad del editor para resolver integrales es limitada. Si no encuentra una solución, no asuma que no existe. Puede buscar fácilmente en Google para encontrar la solución en línea. A veces puede haber varias soluciones. En este caso...Algunas de ellas pueden no ser siempre correctas: se recomienda verificar una solución utilizando integral definida y comparar el resultado del cálculo numérico directo con el basado en la solución.

Cada integral es en realidad una función cuyo nombre es igual al símbolo de la integral. La función también tiene paréntesis que normalmente no se muestran.yAl editarlo, el editor espera encontrar un diferencial dentro de cada término de la expresión.

La posición de los límites para la integral definida se puede cambiar en la configuración: propiedad “Tg, ctg, etc. en lugar de tan, cot, etc.”

Cuando escribes una integral indefinida también verás que aparece un botón de contexto para convertirla en definida.

La expresión de argumento integral también puede contener otra integral junto con una diferencial (es decir, una integral doble o múltiple). Cada integral anidada también debe contener una diferencial entre paréntesis.

Si se desea calcular una integral definida, todas las integrales anidadas deben usar variables diferentes. Si se desea resolver una integral indefinida, todas las integrales anidadas deben usar la misma variable.

Se pueden graficar integrales definidas. Se establece el límite inferior en un valor numérico y una variable como límite superior. Esta variable debe ser diferente de la variable de integración. Se usará para el eje x. Este tipo de gráfico no es exacto y puede ser inestable al cambiar el área del gráfico, especialmente en presencia de singularidad. Esto dependerá del límite inferior y del área del gráfico.

Derivados

Hay tres maneras de escribir (o hallar) la derivada. La primera es usar la derivada como se mencionó anteriormente. La segunda es poner una expresión entre paréntesis y sumarle la potencia.con símbolo primo (similar al apóstrofe) que utiliza un botón de contexto que aparece después de presionar el botón de encendido/exponente (tambiénapóstrofe en el teclado).

(x*sin(x))’

No se requieren paréntesis para una sola función o variable. También se admiten derivadas de orden superior.

La tercera forma es utilizar la fracción de dos diferenciales (notación de Leibniz).

Al escribir una única función diferencial d(), el editor muestra un botón contextual con la fracción. La tercera opción es más fiable cuando se tiene una expresión con varias variables; de lo contrario, no queda claro qué variable se debe usar para la diferenciación.

Si necesita aumentar el orden de la derivada, se hace con los botones contextuales que aparecen al seleccionar la derivada de primer orden. Puede que no...elyque el editor utiliza un especialvisual bbloqueo para derivadas de orden superior y está restringido cómo puedes editarlo.

En ecuaciones diferenciales, se pueden usar las dos últimas formas de denotar la derivada. La tercera forma es aún más fiable, ya que permite al editor comprender mejor la tarea.
