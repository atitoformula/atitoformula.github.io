El editor te permite escribir fórmulas con dos fines: representación visual/impresión, junto con el análisis/cálculo de operaciones matemáticas reales. Puedes utilizar fórmulas que se pueden calcular o resolver, así como fórmulas que son solo para exportar (LaTeX, imagen, etc.), incluyendo texto común y dibujos. Tus fórmulas pueden ser definiciones de variables y funciones, y pueden hacer referencia unas a otras, por lo que es posible escribir programas sencillos que realicen cálculos numéricos.

El editor está disponible como aplicación para Android y como aplicación web.

Edición básica

Ten en cuenta que, en muchos casos, el editor no solo inserta un nuevo símbolo, sino que también corrige lo que has escrito anteriormente.

A medida que escribes, muchos botones del panel principal cambian. Presionar un botón repetidamente puede ajustar lo que se insertó anteriormente. Por ejemplo, al presionar un botón de fracción, este incluirá más términos en el numerador. Para otros botones, solo revisa cómo cambian después de presionarlos una sola vez.

A medida que escribes, aparecen muchos botones adicionales a la izquierda y a la derecha de la pantalla. Se llaman botones contextuales. Por ejemplo, cuando escribes una letra, aparece la lista de funciones que comienzan con esa letra. También puedes seleccionar cualquier elemento, y es posible que aparezcan botones para modificarlo.

Para escribir una letra mayúscula, mantén presionado un botón.

Entre todas las fórmulas que has escrito, el editor busca símbolos que son difíciles de volver a escribir: se agregan en la esquina inferior derecha para un acceso rápido.

Uso de comandos de LaTeX y Unicode

Escribe el nombre completo de un símbolo (comando) en LaTeX y aparecerá un botón para insertarlo. Desplázate por la lista de botones contextuales si es necesario.

Lista de símbolos y comandos compatibles.

Puedes ingresar cualquier símbolo escribiendo su número hexadecimal Unicode. Por ejemplo, escribe «2295» y aparecerá un botón contextual con el símbolo ⊕.

Combinación de caracteres

También puedes combinar un símbolo con otro; por ejemplo, escribe u0303. El número 0303 es el código Unicode del símbolo de la tilde. Aparecerá el botón con la tilde; presiónalo y luego aparecerá un botón con el símbolo ũ, que combina la «u» y la tilde. También puedes combinar más de dos símbolos; por ejemplo, escribe ab0305. El código 0305 es el símbolo de la «barra superior». Reemplaza el código por este nombre, luego selecciona los tres símbolos y verás el botón con la barra superior sobre «ab». Cualquier símbolo combinado se estira para que su ancho sea el mismo que el del texto base. También puedes escribir nombres de LaTeX, por ejemplo, «tilde» en lugar del código 0303.

Exportar/Importar

Puedes exportar fórmulas en varios formatos.

  • LaTeX

Formato LaTeX bien conocido para la representación visual y la impresión de calidad de fórmulas. Sin embargo, no es confiable si quieres restaurar las fórmulas, ya que no está diseñado para conservar exactamente el significado de la fórmula.

Durante la importación, por defecto, se espera que las fórmulas estén entre \[...\] u otros comandos que inicien el modo matemático. Sin embargo, si no se encuentran dichos comandos y parece una fórmula de LaTeX, entonces el modo matemático se habilita desde el inicio.

  • Texto de fórmulas (formato de texto breve)

El formato de texto representa el significado matemático de una fórmula de manera concisa (pero no su apariencia). Es probable que muchas otras aplicaciones lo reconozcan para tipos comunes de fórmulas. Coincide con el lenguaje de Matlab en muchos aspectos, pero no siempre. Es posible que parte de lo que escribas no se pueda convertir a este formato. Puede contener símbolos Unicode (no ASCII) si los utilizas.

  • Datos completos (JSON)

Te permitirá restaurar todas tus fórmulas exactamente como las ves, incluyendo algunos datos adicionales. Solo se puede usar con este editor. No es muy adecuado para ver o editar manualmente. Basado en el formato JSON. En Android, los archivos (*.json) se pueden abrir desde otras aplicaciones (se importarán).

  • PDF, imagen (png)

Imagen PNG que incluye fórmulas y dibujos seleccionados. Durante la importación, también puedes usar JPG y otros formatos. El formato predeterminado para la exportación es PNG, pero se puede cambiar a WebP en la configuración. La calidad de la imagen también se puede modificar en la configuración.

Durante la importación se inserta tal cual: no se escanea la foto para extraer fórmulas, etc. Usa otras apps gratuitas para generar LaTeX a partir de fotos; luego podrás importar el LaTeX.

  • Página web

Copiada en el navegador (HTML). También en la app de Wikipedia. Solo para importar. Se extraerán el texto y las fórmulas (no las imágenes), pero esto no es posible en todas las páginas web. Muchos sitios no permiten extraer fórmulas del HTML copiado. Primero se convertirá a LaTeX, que podrás ver y editar antes de importarlo.

Si no hay ninguna selección, se exportarán todas las fórmulas.

Cuando copias una selección, el editor también la copia al portapapeles del sistema. Por defecto, utiliza el formato de texto. En la configuración se puede cambiar a LaTeX.

En la aplicación web, también puedes copiar la imagen de las fórmulas seleccionadas presionando Ctrl+Shift+C. Para insertar desde el portapapeles del sistema (copiado por otra aplicación), usa Ctrl+Shift+V. El formato de las fórmulas se determinará automáticamente; de lo contrario, se insertarán como un solo bloque de texto.

Diferencias entre la aplicación para Android y la aplicación web

La aplicación para Android suele tener más funciones que la aplicación web.

Funciones de la aplicación para Android que no están presentes en la aplicación web:

  • cálculos numéricos de alta precisión cuando solo se utilizan operaciones aritméticas básicas
  • cálculo de algunas funciones especiales
  • gráficos en 3D
  • fuente personalizada por el usuario para los comentarios

La aplicación web será más lenta y consumirá más batería en dispositivos móviles en comparación con la aplicación para Android.

Uso del teclado

En un dispositivo Android, puedes usar un teclado físico, al igual que en la aplicación web.

Cuando ejecutas la aplicación web en una computadora de escritorio o portátil, la interfaz de usuario se ajusta automáticamente para el uso del teclado. Si realizas alguna acción sin teclado, puede aparecer una nota en la parte superior de la pantalla con el atajo de teclado correspondiente a esa acción.

En la aplicación de Android hay una configuración para habilitar el modo de uso de un teclado físico. Se volverá similar a una aplicación de escritorio.

Puedes presionar el botón de contexto (en el lado izquierdo) presionando la tecla Espacio varias veces mientras mantienes presionada la tecla Ctrl. Puedes presionar el botón de sugerencias (en el lado derecho) presionando la tecla Espacio varias veces mientras mantienes presionadas las teclas Ctrl y Shift. Lo mismo ocurre con las letras escritas recientemente en la esquina inferior derecha (cuando no se muestran las sugerencias).

Funciones

Si escribes unas cuantas letras seguidas de paréntesis, por ejemplo, sin(), significará s*i*n*(), no una llamada a una función (aunque se vea similar). Escribe la primera letra del nombre de la función o el nombre completo, y aparecerá un botón de contexto para insertar la llamada a la función. Para las funciones más conocidas, el editor puede corregirlo automáticamente después de que escribas el nombre de la función seguido de paréntesis. Las llamadas a funciones se mostrarán de manera diferente en comparación con cuando simplemente escribes varias variables seguidas de paréntesis. A continuación, se denominarán simplemente «funciones».

Es posible que el editor no muestre los paréntesis en algunos casos, pero estos aparecerán cuando coloques el cursor dentro o después de la función. Si deseas que los paréntesis se muestren siempre, selecciona la función con su argumento; aparecerá un botón contextual con la misma función, pero con la configuración que hace que los paréntesis se muestren siempre.

No puedes editar el nombre de una función. Esto puede resultar inconveniente si la expresión del argumento es larga. En este caso, simplemente selecciona la función y verás que aparece un botón para copiar solo el argumento. Haz clic en él, escribe el nombre de una nueva función y luego pega el argumento. Como alternativa, también puedes seleccionar la función y escribir solo la primera letra de una nueva función; entonces verás un botón contextual en el que el argumento no estará vacío, sino que será igual al anterior.

Para usar tus propias funciones, simplemente escribe una letra seguida de paréntesis; aparecerá un botón para reemplazarla por una llamada a la función, cuyo nombre contendrá esa sola letra. Para crear una función con un nombre más largo, selecciona algunas letras seguidas de paréntesis vacíos. Ten en cuenta que las funciones de una sola letra pueden mostrarse de manera diferente en comparación con las que tienen nombres largos.

Para definir una función, debes crear una fórmula que incluya esta función llamada con argumentos de una sola letra, seguida de un signo igual y una expresión que haga referencia a esos argumentos.

f(x)=x*x
f(x,y) = x*y

Dondequiera que utilices esa función, se puede calcular o reemplazar fácilmente por su definición si es necesario.

Arrastrar y soltar

Puedes cambiar fácilmente el orden de los multiplicadores o los términos. Solo selecciona uno o más y luego arrastra y suelta la selección en un nuevo lugar. También funciona con fracciones: puedes mover elementos dentro y fuera de una fracción, a otra. También funciona con ecuaciones que contienen fracciones; puedes mover elementos de la parte izquierda de la ecuación a la derecha y viceversa. El editor solo te permitirá realizar movimientos que sean matemáticamente correctos en general.

Cuando selecciones una parte de la fórmula, es posible que veas un botón «Extraer». Es para tu comodidad y te permitirá mover fácilmente la selección a una nueva fórmula, que será la definición de una nueva variable. Solo escribe el nombre de la variable y se insertará en lugar de la selección. Esto sirve para dividir fácilmente fórmulas grandes en otras más pequeñas, que se referencian entre sí a través de los nombres de las variables.

Agregar texto común

Puedes insertar bloques de texto, ya sea para usar variables con nombres largos o para escribir comentarios. El botón «Texto» te permite hacerlo. Aparece cuando creas una nueva fórmula (o cuando escribes «t»). Hay otro botón más abajo en el panel principal.

Aparecerá un cuadro de diálogo para editar el texto, y habrá una opción para elegir si se desea ignorar este texto en la ecuación matemática como comentario o procesarlo como variable.

Más adelante, puedes hacer doble clic para editar el texto.

Si el texto es extenso, aparecerá un botón vertical a la derecha que te permitirá cambiar el ancho del bloque de texto. En la esquina superior derecha del texto también hay un botón para cambiar la alineación.

Cuando escribes variables (la mayoría de los símbolos), cada una va a un bloque de texto separado; solo los dígitos se combinan automáticamente en un solo bloque: número. Por defecto, se aplica el estilo cursiva a las variables de una sola letra, pero no a los bloques de texto más grandes. Cuando escribes (o seleccionas) varios símbolos, también aparece un botón contextual para combinarlos en un solo bloque de texto, y se procesará como una sola variable con un nombre largo (si no hay espacios, etc.). El formato (como cursiva o negrita) se aplica a todo el bloque de texto.

En la app de Android, en la configuración, puedes cargar una fuente personalizada (de https://fonts.google.com/) que se utilizará únicamente para los comentarios. Esta opción no está disponible en todos los dispositivos, ya que requiere los servicios de Google.

Dibujo

El editor también admite el dibujo, implementando muchas características de un editor de gráficos vectoriales. Actívalo en la configuración. Es posible dibujar cualquier forma, aplicar colores, modificar los puntos de la forma, agrupar y cambiar el orden Z. Consulta las guías en video.

Análisis y transformación de expresiones

Al seleccionar cualquier parte de una fórmula, el editor comenzará a buscar entre todas las fórmulas de la biblioteca incorporadas que puedan aplicarse a la expresión seleccionada. Mostrará una lista de todas las demás expresiones posibles que puedan seguir a la original según las reglas matemáticas. También incluye soluciones a problemas matemáticos clásicos. Algunos cálculos complejos se iniciarán solo después de que selecciones una expresión en particular.

La lista de sugerencias puede ser muy larga, pero las mejores sugerencias suelen aparecer entre las primeras. Una sugerencia puede tener un botón que te permite ver información más detallada sobre la fórmula de la biblioteca que se utilizó.

Cuando el editor no puede encontrar una solución, hay un botón en la esquina superior derecha para iniciar una búsqueda en Google.

Al hacer clic en una sugerencia, esta se insertará de forma predeterminada en lugar de la expresión seleccionada. Aparecerá un botón que te permite revertir la acción anterior, duplicar la fórmula original donde estaba la selección y luego realizar el reemplazo en la nueva fórmula sin modificar la anterior. O bien, también puede agregar la expresión sugerida a la seleccionada después del signo igual.

Selecciona una sola variable y el editor te sugerirá más operaciones relacionadas con ella: sustitución, resolución de ecuaciones, etc. En este caso, se transformará toda la fórmula.

Números complejos

Para realizar cálculos con números complejos, solo tienes que incluir el símbolo i en tus fórmulas. Esta función se puede desactivar en la configuración. Existen funciones que te permiten obtener la parte imaginaria y la parte real de un número complejo, así como el argumento y el módulo (Re(z), Im(z), arg(z), |z|).

Usa la función conj para el conjugado complejo.

Trigonometría

Todos los cálculos de funciones trigonométricas se realizan en radianes. El símbolo de grado ° se procesa como una conversión a radianes x / 180 * π; por ejemplo, 45° será 0.7853…

Para escribir el símbolo de grado junto a cualquier número, primero presiona el botón de encendido; luego aparecerá el botón contextual con el símbolo de grado.

se procesa como 1/sin, no como la función trigonométrica inversa. Usa arcsin para eso.

Gráficos

Para ver los gráficos, primero debes seleccionar las fórmulas que se incluirán. Al editar una fórmula, encontrarás un botón a la izquierda para incluirla en los gráficos. Una vez que hayas incluido al menos una fórmula, presiona el botón en la esquina superior izquierda para mostrar los gráficos. Si la fórmula contiene un signo igual, la expresión a la izquierda debe ser un nombre de variable simple o una función como f(x). Sin embargo, puedes representar gráficamente cualquier desigualdad que produzca valores 0 o 1.

Ten en cuenta que, si seleccionas una sola variable en una ecuación, el editor intentará resolverla y construir la expresión para esa variable. También te permitirá ver el gráfico de la función resultante.

El editor comenzará a analizar todas las fórmulas que hayas incluido en el gráfico, revisando de manera recursiva todas las fórmulas que definen las variables utilizadas en las fórmulas iniciales que hayas incluido.

Por ejemplo:

r*c+a   ☑Gráfico
a = 1

r = sin(x)
c = cos(x)

Aunque solo se incluye la primera fórmula, en los cálculos también se utilizan otras.

Al trazar un gráfico habitual (de una sola variable), el editor espera encontrar una sola variable que no tenga ninguna fórmula. Esta se convertirá en la variable del eje x tradicional. Las demás variables (para las que debes definir algunos valores numéricos) se convertirán en parámetros.

Dependiendo de la configuración, la variable «x» puede asumirse como la predeterminada. El resto de las variables se convertirán automáticamente en parámetros con valores iniciales predeterminados (por lo que a=1 es innecesario en el ejemplo anterior).

Al abrir el gráfico, aparecerá un botón en la parte superior para cada parámetro. Presiónalo para comenzar a modificar el valor de un parámetro mediante un control deslizante. Hay dos botones que te permiten cambiar el rango de valores que utiliza el control deslizante. Si necesitas establecer un valor exacto, configúralo en la fórmula de ese parámetro.

Ten en cuenta que cualquier ecuación o definición del tipo x=... (o cualquier variable) puede interferir con los cálculos del gráfico.

Si hay definiciones duplicadas para una variable, aparecerá un signo de exclamación.

Funciones de dos variables

El editor también te permite analizar funciones de dos variables. Traza el tipo de gráfico a color que se suele utilizar para analizar funciones de números complejos (representadas por dos números reales). Pero puedes usarlo para cualquier tipo de función de dos variables. Por ejemplo:

sin(x) + sin(y)    ☑ Gráfico

En este tipo de gráfico, el valor de la función se representa mediante el color. El rojo corresponde al valor máximo de la función, mientras que el azul corresponde al valor mínimo. Cada variable se corresponde con uno de los ejes.

Los valores mínimos y máximos se calculan únicamente dentro del área mostrada. Al desplazarse a otra área, estos valores pueden cambiar significativamente, pero siempre habrá una distribución de colores entre el rojo y el azul. La correspondencia entre el valor de la función y el color no está fijada inicialmente.  Es posible que primero debas encontrar un área que produzca valores mínimos y máximos adecuados (sin singularidades en ella) y, luego, presionar el botón «Colores bloqueados» en la esquina superior derecha, lo cual fijará los colores recordando los valores mínimos y máximos actuales.

El brillo también cambiará ligeramente para mostrar los contornos de la función variable.

Los valores cercanos a cero se marcan con color azul oscuro. El umbral (de cuán cerca de cero) puede cambiar, pero los valores con valor absoluto > 1 nunca se marcan.

La distribución de colores entre el rojo y el azul no siempre permite ver fácilmente cómo cambia la función. Existe el modo de ondas, que te permite dividir la única onda roja y azul en varias. En este modo, el color ya no te permitirá ver dónde se encuentran el mínimo o el máximo.

Las variables no tienen por qué ser x e y. El editor analizará tus fórmulas e intentará encontrar exactamente dos variables sin definiciones; sin embargo, si se encuentran varias, se asumirá que x e y son las predeterminadas.

Coloreado del dominio (funciones complejas)

También hay un modo especial para cuando tienes dos funciones de dos variables. En este caso, una «función principal» puede definir la distribución de colores entre el rojo y el azul, tal como se explicó anteriormente. Una segunda función puede definir el brillo desde el negro hasta el color más brillante (coloreado del dominio). Puedes configurar la función principal haciendo clic en ella en la esquina inferior izquierda.

Se utiliza principalmente para funciones que devuelven un número complejo.

z = x + i*y
f=(z*z-2)/(1-2*i-z)    ☑Gráfico

Dicha función se divide en dos: el argumento (ángulo) del número complejo calculado «f» y el valor absoluto. Hay un botón en la esquina superior derecha (coloreado del dominio) que te permite habilitar o deshabilitar el cambio de brillo mediante la segunda función. Cuando está deshabilitado, solo se representa gráficamente la función principal seleccionada como una sola.

Los botones que bloquean los colores o cambian al modo de ondas se aplicarán a la función principal actual. Si quieres ajustar la distribución del brillo, debes convertir temporalmente a la segunda función en la principal; después de ajustar la distribución del color a tu gusto, vuelve a establecer esta función como secundaria.

Si quieres representar gráficamente una función con argumento complejo, el editor te permite representar solo esta función. Como solución alternativa, puedes ajustar la fórmula y convertir el número complejo en uno real (utilizando Re(z), Im(z), arg(z), |z|) y luego representar gráficamente cualquier número de funciones de este tipo.

Coordenadas polares y ecuaciones paramétricas

Para mostrar la gráfica de una curva utilizando coordenadas polares, incluye dos ecuaciones con una sola variable:

r=u          ☑Gráfico
𝜑 = 20u    ☑ Gráfico

r: distancia desde el centro de coordenadas; 𝜑: ángulo en radianes.

Algo muy similar ocurre con las ecuaciones paramétricas:

x = u * sin(10u)     ☑ Gráfico
y = u * cos(20u)     ☑ Gráfico

Las ecuaciones también se pueden combinar en un sistema.

El intervalo de variación de la variable siempre va de 0 a 1. Puedes agregar fórmulas como u = 2πu₁, entonces u₁ se convierte en variable y u varía de 0 a 2π.

Gráfico en 3D

Solo para Android.

Verás el botón de gráfico «3D» a la derecha cuando representes gráficamente una función de dos variables f(x,y) como se describió anteriormente (inicialmente verás la vista anterior en el gráfico 3D y podrás cambiar el área XY). Cuando se abre el modo 3D, ya no es posible cambiar el área XY; solo puedes rotar la cámara alrededor del centro de la superficie mostrada.

Habrá un botón para activar el modo de vuelo, en el que podrás cambiar la posición y la orientación de la cámara variando la velocidad y girando como en un juego.

Una superficie representada por las funciones f(x,y) se denomina superficie explícita.

Superficie paramétrica

Al representar gráficamente ecuaciones como x=…, y=…, z=…, se abre el gráfico 3D de una superficie paramétrica. El intervalo de variación de cada variable es siempre de 0 a 1. Puedes agregar fórmulas como u=2πu₁; en ese caso, u₁ se convierte en variable y u varía de 0 a 2π. Por ejemplo:

x = v * sin(u)    ☑ Gráfico
y = v * cos(u)   ☑ Gráfico
z = vu                ☑ Gráfico
v = 3v₁
u = 2πu₁

Las ecuaciones se pueden combinar en un sistema para mayor comodidad, especialmente en el caso de múltiples superficies.

Los nombres de las variables pueden ser diferentes: debe haber dos variables sin definir. Sin embargo, no pueden ser x, y ni z.

En el caso habitual hay dos variables; en el caso de una sola, la gráfica se mostrará como un túnel en el espacio 3D (esencialmente una curva).

Si quieres representar gráficamente una superficie paramétrica, todas las funciones que se agreguen a los gráficos deben ser superficies paramétricas.

Creación de mundos 3D

Solo para Android.

El editor te permite representar gráficamente múltiples superficies paramétricas, usar tus imágenes como texturas y modificar muchos otros parámetros para diseñar mundos 3D interesantes con el poder de las matemáticas.

Una sola superficie se representa mediante un sistema de ecuaciones x=, y=, z=. Puedes usar múltiples sistemas en una sola fórmula combinándolos mediante la operación de suma.

También puedes usar funciones de suma

Esto creará 12 superficies con diferentes posiciones.

También puedes definir funciones y utilizarlas:

Solo necesitas trazar la primera. Cada función debe tener al menos un parámetro, aunque no lo necesites.

Dentro del sistema puedes agregar varios parámetros, como «resolution» arriba.

Ten en cuenta que cada parámetro es un bloque de texto único y está marcado como nombre de variable (no como comentario). Escribe las dos primeras letras del nombre (dentro del sistema) y aparecerá un botón contextual para insertarlo.

resolution

Define cuántos puntos se calcularán (resolution * resolution) y qué tan suave será la superficie. También determina en gran medida la memoria asignada y el tiempo de cálculo. Si tienes varias superficies, siempre debes tratar de reducir ese parámetro tanto como sea posible, sin dejar de mantener una apariencia aceptable.

Si el valor es 3 (el mínimo permitido), tendrás 9 puntos con valores de los parámetros 0, 0.5, 1.

También se pueden utilizar «resolutionU» y «resolutionV» para establecer una resolución diferente para cada dimensión.

texture

Índice de la imagen en el lienzo. El índice 1 corresponderá a la imagen más grande (la más grande en términos del área tal como se muestra realmente en el lienzo; puedes cambiar su tamaño fácilmente). La imagen se dibujará para cubrir la superficie.

stretch

Define cuánto se estirará la textura, es decir, qué tan grande se verá (en ambas direcciones, conservando la relación de aspecto).

stretch2

Define un estiramiento adicional solo en una dirección. Esto modificará la relación de aspecto de la textura.

stretchType

Valores: 0 (predeterminado), 1, 2. Define el método de dibujo de la textura. Si el resultado no se ve bien en algunas partes, conviene probar otros métodos.

textureRotate

Valores 0 (predeterminado) o 1. El valor 1 hará que la textura gire 90 grados. Es como intercambiar los parámetros de superficie (u->v, v->u) en las fórmulas.

brightness

Valores fraccionarios de -1 a 1. El valor predeterminado es 0. Modifica el brillo de la superficie cuando se utiliza una textura.

color

Valor entero único en formato RGB (rojo, verde, azul). 255 significa azul, 255*256 significa verde. Es mejor usar la función «hex» y un valor hexadecimal; por ejemplo, hex(ff0000) significa rojo.

smooth

  • valor 0: la superficie tendrá bordes bien definidos entre los distintos segmentos planos;
  • valor 1 (por defecto): los bordes serán menos visibles, excepto en caso de un cambio de ángulo grande y repentino (como en un cubo);
  • valor 2: todos los bordes son menos visibles; incluso un cubo se verá como otra cosa

zOffset

Cuando hay varias superficies en un mismo lugar (que se superponen o encajan estrechamente), se produce un conflicto sobre cuál debe dibujarse encima de la otra. Pueden producirse fallos durante el dibujo. El valor -1 especifica que la superficie debe dibujarse encima. El valor 1 significa que se dibuja detrás. El valor predeterminado es 0. Puedes usar otros valores fraccionarios para definir el orden, pero por lo general basta con 1 o -1.

background

El valor 0 (por defecto) o 1 significa que la superficie forma parte del fondo: cielo, sol, luna (objetos lejanos). Durante la visualización de dicha superficie, la cámara siempre se ubica en el centro de las coordenadas; cambiar la posición no modificará el aspecto de la superficie (su tamaño).

lines

Valor 0 o 1 (por defecto). Establece si se deben mostrar líneas de contorno sobre la superficie (cuando no hay textura).

border

Específico del juego. Si es 1, la superficie no se muestra, sino que se utiliza como un borde invisible para los objetos de destino en el juego. Esto permite controlar mejor a dónde pueden ir.

ignore

Específico del juego. Si es 1, los objetos objetivo no volarán sobre la superficie (no se adherirán a ella). De lo contrario, como es habitual, intentarán mantenerse cerca de alguna superficie durante un tiempo.

Existe la opción de iniciar un juego en cualquier gráfico 3D que construyas. El objetivo es perseguir y disparar a los objetivos que se mueven a lo largo de las superficies creadas.

Existen parámetros globales que se aplican al juego. Puedes agregarlos en el lienzo en cualquier lugar como una ecuación independiente.

Por ejemplo:

posiciones

Define las posiciones iniciales permitidas del jugador y de los objetos objetivo. El valor es un sistema de ecuaciones similar al de una superficie 3D. Los objetos se distribuirán al azar a lo largo de la superficie.

tamaño

Tamaño del jugador y de los objetivos. Cuanto más pequeño sea el tamaño, más grande parecerá el mundo.

El valor predeterminado es 1, lo que significa un tamaño predeterminado que depende del tamaño del mundo 3D. Un valor de 0,5 significará la mitad del tamaño predeterminado. Un valor demasiado pequeño puede causar problemas con los gráficos.

Función f(x,y,z)

En el caso de la función de las variables x, y, z, se muestra un 3D especial con pequeñas partículas distribuidas por todo el volumen del espacio. Cuanto mayor sea el valor de la función, mayor será la concentración de partículas. El color de las partículas también puede cambiar de azul (valor bajo) a rojo (valor alto).

 sin(x) + sin(y) + sin(z) ☑ Gráfico

Consulta también más abajo la información sobre superficies implícitas f(x,y,z) = 0.

Habrá varios parámetros para ajustar la gráfica:

  • x0, y0, z0 y 𝚫xyz se utilizan para modificar la región del espacio;
  • «Res» se utiliza para cambiar la resolución de la malla 3D con la que se calcula la función.
    Un valor más alto significa mejor calidad del gráfico y un cálculo más largo;
  • «Den» se utiliza para despejar el espacio donde la función es pequeña. Los valores van de 0 a 1. Si la función varía de 0 a 10 y Den = 0,3, entonces solo el rango de 3 a 10 mostrará partículas, mientras que de 0 a 3 será espacio despejado. Para superficies implícitas es mejor mantenerlo en 0; de lo contrario, mantén un valor más alto (alrededor de 0,3).

Ecuaciones y curvas/superficies implícitas

Cuando se representa gráficamente una ecuación con una sola variable f(x)=g(x), la parte derecha se desplaza hacia la izquierda y se muestra la gráfica de f(x)-g(x). Las intersecciones con el cero marcan la solución.

En la gráfica de una ecuación genérica con 2 o 3 variables, por ejemplo, f(x,y) = g(x,y), esta se convierte en la inversa de la diferencia 1/|f(x,y) - g(x,y)|. Se muestra el mismo tipo de gráfica que para las funciones de dos variables descritas anteriormente, pero en modo blanco y negro. Un valor más alto significa que se acerca más a la igualdad. Si ves curvas delgadas bien definidas, estas muestran la solución de la ecuación.

Con tres variables se utiliza el mismo principio, pero basado en el gráfico tridimensional de f(x, y, z) descrito anteriormente.

Sin embargo, ten en cuenta que y = x² se representa gráficamente como x². No se procesa como una ecuación, sino como la definición de la función llamada y.

Desigualdades

Las desigualdades se procesan como funciones que producen 0 o 1 como resultado. Los sistemas de desigualdades se pueden calcular y representar gráficamente como una conjunción (Y) de desigualdades. El modo en blanco y negro se activa automáticamente cuando hay dos variables.

Sistemas de ecuaciones

El editor puede resolver sistemas de ecuaciones lineales.

No estás limitado a usar solo coeficientes numéricos. Si usas varias variables, el editor asumirá que el número de variables reales es igual al número de ecuaciones. El resto de las variables se considerarán parte de los coeficientes. Es posible que veas varias soluciones dependiendo de qué variables reales se elijan. Funciones como sin(x) también pueden considerarse variables.

Puedes escribir un sistema en forma matricial y convertirlo a forma clásica, y viceversa.

Al seleccionar un sistema, es posible que notes que aparece un botón de contexto con el mismo sistema, pero con una columna adicional de condiciones. Se calcula como una función por tramos. La condición en la última fila es opcional.

Matrices

Con las matrices y los vectores (caso particular de una matriz), el editor realizará una operación similar a la de los números, excepto que en este caso no realiza cálculos numéricos, sino transformaciones de expresiones arbitrarias que producen una única matriz de resultado. Si defines una variable como matriz, todas las demás fórmulas que la incluyan se calcularán como matrices. Sin embargo, en algunos casos puede tratarse de una matriz de una sola celda. El editor muestra el tamaño de la matriz calculada para cada fórmula.

En el caso de una matriz de una sola celda, puede mostrar un valor numérico.

También puedes seleccionar cualquier parte de la fórmula y el editor calculará la matriz si algunas variables son matrices.

Puedes obtener el valor de una celda de la matriz utilizando un índice. Escribe el nombre de la matriz en minúsculas y luego escribe el índice con un valor numérico, por ejemplo:

M=[4,5,3]
m₁ es 4

Si una matriz tiene alguna dimensión con tamaño 1, entonces el índice se aplicará a otra dimensión. Si ambas dimensiones son mayores que uno, entonces el primer dígito del número será el índice de la fila y el segundo dígito, el índice de la columna. Opcionalmente, se puede usar una coma entre dos números.

Es posible hallar la matriz inversa o elevar una matriz a una potencia entera.

Para utilizar la transposición, puedes agregar la potencia «T» a una variable, pero para la etiqueta de la matriz hay un botón contextual especial para hacerlo que aparece cuando editas una matriz.

Si utilizas tus propias funciones, estas pueden aceptar una matriz como argumento o devolver cualquier otra matriz basada en las expresiones que escribas. El caso será diferente cuando utilices funciones conocidas como «sin», que solo funciona con argumentos numéricos. Esta función se aplicará a cada celda de la matriz si la pasas como argumento; siempre se devolverá otra matriz con las mismas dimensiones. Lo mismo se aplicará a todas las funciones comunes que no puedan procesar matrices como argumentos. Si utilizas tus propias funciones, durante los cálculos matriciales todas se expanden, es decir, se reemplazan por su definición.

Si necesitas calcular el producto vectorial de dos vectores, utiliza la función «cross». El símbolo «cross» se utiliza como separador opcional y, por lo general, se ignora.

Cálculo

Para usar un diferencial (como dx), debes utilizar la función con el nombre «d» (escribir d seguido de x no se interpretará como un diferencial; el botón contextual con la función aparece al escribir la letra d). Cuando escribes un argumento simple como x, se mostrará simplemente como dx. También puedes escribir cualquier expresión. Al seleccionar la función, el editor intentará hallar la derivada de la expresión del argumento.

Integrales

Al escribir la letra «i», aparecerá un botón de contexto de integral.

La capacidad del editor para resolver integrales es limitada. Si no puede encontrar una solución, no debes dar por sentado que no existe ninguna. Puedes enviarla fácilmente a la búsqueda de Google para encontrar una solución en línea. A veces puede haber varias soluciones. En este caso, es posible que algunas de ellas no siempre sean correctas: se recomienda verificar una solución utilizando una integral definida y comparar el resultado del cálculo numérico directo con el basado en la solución.

Cada integral es, en realidad, una función cuyo nombre es igual al símbolo de la integral. La función también tiene paréntesis que, por lo general, no se muestran, salvo cuando la editas. El editor espera encontrar una derivada dentro de cada término de la expresión del argumento.

La posición de los límites de la integral definida se puede cambiar en la configuración: propiedad «Tg, ctg, etc. en lugar de tan, cot, etc.».

Al escribir una integral indefinida, también verás que aparece un botón contextual para convertirla en definida.

La expresión del argumento de la integral también puede contener una sola integral anidada junto con una diferencial (lo que significa una integral doble o múltiple). Cada integral anidada también debe contener una sola diferencial entre paréntesis.

∫(∫(x dx) dx)

Si quieres calcular una integral definida, todas las integrales anidadas deben usar variables diferentes. Si quieres resolver una integral indefinida, todas las integrales anidadas deben usar la misma variable.

Puedes representar gráficamente integrales definidas. Establece el límite inferior en algún valor numérico y establece alguna variable como límite superior. Esta variable debe ser diferente de la variable de integración. Se utilizará para el eje x. Dicha gráfica no es exacta y puede no ser estable cuando cambias el área de la gráfica, especialmente en presencia de una singularidad. Dependerá del límite inferior y del área de la gráfica.

Derivadas

Hay tres formas de escribir (o hallar) derivadas. La primera es utilizar un diferencial, como se mencionó anteriormente. La segunda forma es colocar una expresión entre paréntesis, agregar una potencia con el símbolo de la prima (similar al apóstrofo) utilizando un botón contextual que aparece después de presionar el botón de potencia/exponente (también el apóstrofo en el teclado).

(x*sin(x))’

No se requieren paréntesis para una sola función o variable. También se admiten derivadas de orden superior.

La tercera forma consiste en utilizar la fracción de dos diferenciales (notación de Leibniz).

Cuando escribes un diferencial simple como la función d(), el editor muestra un botón contextual con la fracción. La tercera forma es más confiable cuando tienes una expresión con múltiples variables; de lo contrario, no quedará claro qué variable se debe usar para derivar.

En ecuaciones diferenciales puedes usar las dos últimas formas para denotar una derivada. La tercera forma sigue siendo más confiable para que el editor comprenda mejor la tarea.

El editor también conoce muchas fórmulas para resolver ecuaciones diferenciales, incluidas las ecuaciones diferenciales lineales de segundo orden. Sin embargo, en algunos casos no sugerirá una solución final, sino solo el siguiente paso posible. Es posible que tengas que armar tú mismo la secuencia correcta de pasos.
