O editor permite que você digite fórmulas com dois objetivos: representação visual/impressão, juntamente com análise/cálculo matemático propriamente dito. Você pode usar fórmulas que podem ser calculadas ou resolvidas, bem como fórmulas destinadas apenas à exportação (LaTeX, imagem etc.), incluindo texto comum e desenhos. Suas fórmulas podem ser definições de variáveis e funções, referenciando-se mutuamente, de modo que é possível escrever programas simples que realizam cálculos numéricos.

O editor está disponível como aplicativo para Android e como aplicativo web.

Edição básica

Observe que, em muitos casos, o editor não apenas insere um novo símbolo, mas também corrige o que você digitou anteriormente.

À medida que você digita, vários botões no painel principal mudam. Pressionar um botão repetidamente pode ajustar o que foi inserido anteriormente. Por exemplo, pressionar um botão de fração fará com que ele inclua mais termos no numerador. Para outros botões, basta verificar como eles mudam depois que você os pressiona uma única vez.

Muitos botões adicionais aparecem à esquerda e à direita da tela conforme você digita. Eles são chamados de botões de contexto. Por exemplo, quando você digita uma letra, aparece a lista de funções que começam com essa letra. Você também pode selecionar qualquer elemento, e botões podem aparecer para alterá-lo.

Para digitar uma letra maiúscula, mantenha um botão pressionado.

Entre todas as fórmulas que você digitou, o editor procura símbolos que são difíceis de digitar novamente: eles são adicionados no canto inferior direito para acesso rápido.

Usando comandos LaTeX e Unicode

Digite o nome completo de um símbolo (comando) em LaTeX e um botão aparecerá para inseri-lo. Percorra a lista de botões de contexto, se necessário.

Lista de símbolos e comandos suportados.

Você pode inserir qualquer símbolo digitando seu número hexadecimal Unicode. Por exemplo, digite “2295” e um botão de contexto com o símbolo ⊕ aparecerá.

Combinação de caracteres

Você também pode combinar um símbolo com outro; por exemplo, digite u0303. O número 0303 é o código Unicode do símbolo til. O botão com o til aparecerá; pressione-o e, em seguida, aparecerá um botão com o símbolo ũ, que combina o u com o til. Você também pode combinar mais de dois símbolos; por exemplo, digite ab0305. O código 0305 é o símbolo “barra superior”. Substitua o código por ele, selecione todos os três símbolos e você verá o botão com a barra superior acima de “ab”. Qualquer símbolo de combinação é esticado para que sua largura seja igual à do texto base. Você também pode digitar nomes em LaTeX, por exemplo, “tilde” em vez do código 0303.

Exportar/Importar

Você pode exportar fórmulas em vários formatos.

  • LaTeX

Formato LaTeX bem conhecido para representação visual e impressão de qualidade de fórmulas. No entanto, ele não é confiável se você quiser restaurar as fórmulas posteriormente, pois não foi projetado para preservar exatamente o significado da fórmula.

Durante a importação, por padrão, espera-se que as fórmulas estejam entre \[...\] ou outros comandos que iniciem o modo matemático. No entanto, se tais comandos não forem encontrados e a fórmula se parecer com uma fórmula LaTeX, o modo matemático será ativado desde o início.

Nas configurações, você também pode especificar expressões regulares (regex), que serão aplicadas para fazer substituições no LaTeX exportado. Por exemplo:

\\mathrm==\\textrm  

_(\w+)==_\\textrm{$1}

Uma instrução por linha. O símbolo \ deve ser escapado. A parte à esquerda, antes de ==, especifica a expressão regular a ser pesquisada. A parte à direita — o texto pelo qual substituir. Ela pode conter referências a grupos capturados ($1). A expressão regular é específica do Java.

Nas configurações, você também pode especificar o uso do LaTeX ao clicar no botão “Copiar”.

  • Texto de fórmulas (formato de texto curto)

O formato de texto representa o significado matemático de uma fórmula de forma resumida (mas não sua aparência). É provável que seja reconhecido por muitos outros aplicativos para tipos comuns de fórmulas. É semelhante à linguagem Matlab em muitos aspectos, mas nem sempre. Parte do que você digitar pode não ser possível converter para este formato. Pode conter símbolos Unicode (não ASCII) quando você os utilizar. Por exemplo:

sin(x+y)*cos(y)-x^2/y^2+x*y+sin(x)^2

  • Dados completos (json)

Permite restaurar todas as suas fórmulas exatamente como aparecem, incluindo alguns dados adicionais. Pode ser usado apenas por este editor. Não é muito adequado para visualização/edição manual. Baseado no formato JSON. No Android, os arquivos (*.json) podem ser abertos em outros aplicativos (que farão a importação).

  • PDF, Imagem (png)

Imagem PNG que inclui fórmulas e desenhos selecionados. Durante a importação, você também pode usar JPG e outros tipos. O PNG é o padrão para exportação, mas pode ser alterado para WebP nas configurações. A qualidade da imagem também pode ser alterada nas configurações.

Durante a importação, ela é inserida tal como está: não há digitalização da foto para extrair fórmulas, etc. Use outros aplicativos gratuitos para gerar LaTeX a partir de fotos; depois, você poderá importar o LaTeX.

  • Página da Web

Copiada no navegador (HTML). Também no aplicativo da Wikipédia. Apenas para importação. O texto e as fórmulas serão extraídos (não as imagens), mas isso não é possível para todas as páginas da web. Muitos sites não permitem que você extraia fórmulas do HTML copiado. O conteúdo será primeiro convertido para LaTeX, que você poderá visualizar e editar antes da importação.

Se não houver seleção, todas as fórmulas serão exportadas.

Quando você copia uma seleção, o editor também faz a cópia para a área de transferência do sistema. Por padrão, ele usa o formato de texto. Nas configurações, isso pode ser alterado para LaTeX.

No aplicativo web, você também pode copiar a imagem das fórmulas selecionadas pressionando Ctrl+Shift+C. Para inserir a partir da área de transferência do sistema (copiada por outro aplicativo), use Ctrl+Shift+V. O formato das fórmulas será determinado automaticamente; caso contrário, elas serão inseridas como um único bloco de texto.

Diferença entre o aplicativo para Android e o aplicativo web

O aplicativo para Android geralmente possui mais recursos do que o aplicativo web.

Recursos do aplicativo para Android que não estão presentes no aplicativo web:

  • cálculos numéricos com alta precisão quando são utilizadas apenas operações aritméticas básicas
  • cálculo de algumas funções especiais
  • gráfico 3D
  • fonte personalizada pelo usuário para comentários

O aplicativo web será mais lento e consumirá mais bateria em dispositivos móveis em comparação com o aplicativo para Android.

Uso do teclado

Em um dispositivo Android, você pode usar um teclado físico, assim como no aplicativo web.

Ao executar o aplicativo web em um PC de mesa ou laptop, a interface do usuário é ajustada automaticamente para o uso do teclado. Se você realizar alguma ação sem o teclado, uma nota poderá aparecer na parte superior da tela com o atalho de teclado para essa ação.

No aplicativo para Android, há uma configuração para ativar o modo de uso de um teclado físico. Ele ficará semelhante a um aplicativo de desktop.

Você pode pressionar o botão de contexto (no lado esquerdo) pressionando a tecla Espaço várias vezes enquanto mantém pressionada a tecla Ctrl. Você pode pressionar o botão de sugestões (no lado direito) pressionando a tecla Espaço várias vezes enquanto mantém pressionadas as teclas Ctrl e Shift. O mesmo vale para as letras digitadas recentemente no canto inferior direito (quando as sugestões não são exibidas).

Funções

Se você digitar algumas letras seguidas de parênteses, por exemplo, sin(), isso significará s*i*n*(), e não uma chamada de função (embora pareça semelhante). Digite a primeira letra do nome da função ou o nome completo, e um botão de contexto aparecerá para inserir a chamada de função. Para funções bem conhecidas, o editor pode corrigi-la automaticamente depois que você digitar o nome da função seguido de parênteses. As chamadas de função serão exibidas de maneira diferente em comparação com quando você simplesmente digita várias variáveis seguidas de parênteses. A seguir, elas serão chamadas simplesmente de funções.

O editor pode não exibir parênteses em alguns casos, mas eles aparecem quando você posiciona o cursor dentro ou após a função. Se quiser que os parênteses sejam sempre exibidos, selecione a função com o argumento; um botão de contexto aparecerá com a mesma função, apresentando a configuração que faz com que os parênteses sejam sempre exibidos.

Não é possível editar o nome de uma função. Isso pode ser inconveniente se a expressão do argumento for longa. Nesse caso, basta selecionar a função e você verá que aparece um botão para copiar apenas o argumento. Clique nele, digite uma nova função e cole o argumento. Como alternativa, você também pode selecionar a função e digitar apenas a primeira letra de uma nova função; então, verá um botão de contexto em que o argumento não está vazio, mas é igual ao anterior.

Para usar suas próprias funções, basta digitar uma letra seguida de parênteses; um botão aparecerá para substituí-la por uma chamada de função que terá essa única letra em seu nome. Para criar uma função com um nome mais longo, selecione algumas letras com parênteses vazios após elas. Observe que funções de uma única letra podem ser exibidas de maneira diferente em comparação com aquelas com nomes longos.

Para definir uma função, você deve criar uma fórmula que chame essa função com argumentos de uma única letra, seguidos do sinal de igual e de uma expressão que faça referência a esses argumentos.

f(x)=x*x
f(x,y) = x*y

Onde quer que você use essa função, ela pode ser calculada ou facilmente substituída por sua definição, se necessário.

Funções recursivas

Para uma função recursiva geral, você pode usar um sistema com condições (observe que o botão de contexto aparece depois que você digita um sistema). Abaixo está um exemplo para a sequência de Fibonacci.

f(6) será calculado como 8.

O número de recursões pode ser limitado. Para uma implementação mais rápida de funções recursivas, use a função especial recur. Consulte a seção sobre gráficos de fractais.

Arrastar e soltar

Você pode alterar facilmente a ordem dos multiplicadores ou termos. Basta selecionar um ou mais e, em seguida, arrastar e soltar a seleção em um novo local. Isso também funciona com frações: você pode mover elementos para dentro ou para fora de uma fração, para outra. Também funciona com equações que contêm frações; você pode mover elementos da parte esquerda da equação para a direita e vice-versa. O editor permitirá apenas movimentos que sejam matematicamente corretos.

Ao selecionar uma parte da fórmula, você poderá ver um botão “Extrair”. Ele serve para facilitar e permite que você mova facilmente a seleção para uma nova fórmula, que será a definição de uma nova variável. Basta digitar o nome da variável e ela será inserida no lugar da seleção. Isso serve para dividir facilmente fórmulas grandes em fórmulas menores, referenciando-as entre si por meio dos nomes das variáveis.

Adicionando texto comum

Você pode inserir blocos de texto tanto para usar variáveis com nomes longos quanto para escrever comentários. O botão “Texto” permite que você faça isso. Ele aparece quando você cria uma nova fórmula (ou digita ‘t’). Há outro botão abaixo, no painel principal.

Uma caixa de diálogo será exibida para editar o texto, e haverá uma opção para escolher se esse texto deve ser ignorado na matemática como um comentário ou se deve ser tratado como uma variável.

Posteriormente, você pode clicar duas vezes para editar o texto.

Quando o texto for grande, um botão vertical aparecerá à direita para permitir que você altere a largura do bloco de texto. No canto superior direito do texto, há também um botão para alterar o alinhamento.

Quando você digita variáveis (a maioria dos símbolos), cada uma delas vai para um bloco de texto separado; apenas os dígitos são combinados automaticamente em um único bloco: número. O estilo itálico é aplicado por padrão a variáveis de uma única letra, mas não a blocos de texto maiores. Ao digitar (ou selecionar) vários símbolos, um botão de contexto também aparece para combiná-los em um único bloco de texto, e ele será processado como uma única variável com nome longo (se não houver espaços, etc.). A formatação (como itálico ou negrito) é aplicada a todo o bloco de texto.

No aplicativo para Android, nas configurações, você pode carregar uma fonte personalizada (em https://fonts.google.com/), que será usada apenas para comentários. Essa opção não está disponível em todos os dispositivos, pois requer os serviços do Google.

Desenho

O editor também oferece suporte ao desenho, implementando diversos recursos de um editor de gráficos vetoriais. Ative-o nas configurações. É possível desenhar qualquer forma, aplicar cores, alterar os pontos da forma, agrupar e alterar a ordem de sobreposição. Veja os tutoriais em vídeo.

Análise e transformação de expressões

Ao selecionar qualquer parte de uma fórmula, o editor começará a pesquisar entre todas as fórmulas da biblioteca incorporadas que podem ser aplicadas à expressão selecionada. Ele listará todas as outras expressões possíveis que podem seguir a original com base em regras matemáticas. Também inclui soluções para exercícios clássicos de matemática. Alguns cálculos complexos só serão iniciados depois que você selecionar uma expressão específica.

A lista de sugestões pode ser muito longa, mas as melhores sugestões geralmente aparecem entre as primeiras. Uma sugestão pode ter um botão que permite ver informações mais detalhadas sobre a fórmula da biblioteca que foi usada.

Quando o editor não consegue encontrar uma solução, há um botão no canto superior direito para iniciar uma busca no Google.

Ao clicar em uma sugestão, ela será inserida por padrão, substituindo a expressão selecionada. Aparecerá um botão que permite reverter a ação anterior, duplicar a fórmula original no local da seleção e, em seguida, fazer a substituição na nova fórmula, mantendo a antiga inalterada. Ou também é possível acrescentar a expressão sugerida à expressão selecionada, após o sinal de igual.

Selecione uma única variável e o editor sugerirá mais operações relacionadas a ela: substituição, resolução de equações etc. Nesse caso, toda a fórmula será transformada.

Números complexos

Para fazer cálculos com números complexos, basta incluir o símbolo i em suas fórmulas. Essa função pode ser desativada nas configurações. Existem funções que permitem obter a parte imaginária e a parte real de um número complexo, bem como o argumento e o módulo (Re(z), Im(z), arg(z), |z|).

Use a função conj para o conjugado complexo.

Trigonometria

Todos os cálculos de funções trigonométricas são realizados em radianos. O símbolo de grau ° é processado como uma conversão para radianos x / 180 * π; por exemplo, 45° será 0,7853…

Para digitar o símbolo de grau para qualquer número, pressione primeiro o botão liga/desliga; em seguida, o botão de contexto com o símbolo de grau será exibido.

é processado como 1/sin, e não como a função trigonométrica inversa. Use arcsin para isso.

Gráficos

Para visualizar gráficos, primeiro você precisa selecionar as fórmulas que serão incluídas. Ao editar uma fórmula, há um botão à esquerda para incluí-la nos gráficos. Depois de incluir pelo menos uma fórmula, pressione o botão no canto superior esquerdo para exibir os gráficos. Se a fórmula contiver um sinal de igual, a expressão à esquerda deve ser um nome de variável simples ou uma função como f(x). No entanto, é possível representar graficamente qualquer desigualdade que produza os valores 0 ou 1.

Observe que, se você selecionar uma única variável em uma equação, o editor tentará resolver e construir a expressão para essa variável. Ele também permitirá que você visualize o gráfico da função resultante.

O editor começará a analisar todas as fórmulas que você incluiu no gráfico, examinando recursivamente todas as fórmulas que definem as variáveis utilizadas nas fórmulas iniciais que você incluiu.

Por exemplo:

r*c+a         ☑Gráfico
a=1

r = sin(x)
c = cos(x)

Embora apenas a primeira fórmula esteja incluída, outras também são utilizadas nos cálculos.

Ao construir um gráfico comum (de uma única variável), o editor espera encontrar uma única variável que não tenha nenhuma fórmula. Ela se tornará a variável do eixo x tradicional. Outras variáveis (para as quais você deve definir alguns valores numéricos) se tornarão parâmetros.

Todas as definições como r=sin(x) tornam-se funções automaticamente no gráfico. Não é necessário escrever f(x)=sin(x).

Dependendo das configurações, a variável “x” pode ser considerada como a padrão. As demais variáveis se tornarão parâmetros automaticamente com valores padrão iniciais (nesse caso, a=1 é desnecessário no exemplo acima).

Quando o gráfico for aberto, haverá um botão na parte superior para cada parâmetro. Pressione-o para começar a alterar o valor de um parâmetro usando um controle deslizante. Existem dois botões que permitem alterar o intervalo de valores usado pelo controle deslizante. Se você precisar definir um valor exato, defina-o na fórmula desse parâmetro.

Observe que qualquer equação/definição do tipo x=... (ou qualquer variável) pode interferir nos cálculos do gráfico.

Se houver definições duplicadas para uma variável, um ponto de exclamação será exibido.

Função f(x,y)

O editor também permite analisar funções de dois argumentos (variáveis). Ele desenha o tipo de gráfico colorido (semelhante a um mapa de calor) que geralmente é usado para analisar funções de números complexos (representados por dois números reais). Mas você pode usá-lo para qualquer tipo de função de duas variáveis. Por exemplo:

sin(x)+sin(y)       ☑Gráfico

Nesse tipo de gráfico, o valor da função é representado por cores. O valor em vermelho corresponde ao valor máximo da função, e o valor em azul — ao valor mínimo. Cada variável corresponde a um eixo.

Os valores mínimo e máximo são calculados apenas dentro da área exibida. Ao se deslocar para outra área, esses valores podem mudar significativamente, mas sempre haverá a distribuição de cores entre o vermelho e o azul. A correspondência entre o valor da função e a cor não é fixa inicialmente.  Pode ser necessário primeiro encontrar uma área que produza valores mínimo e máximo adequados (sem singularidades), e então pressionar o botão “Cores bloqueadas”, no canto superior direito, que fixará as cores, memorizando os valores mínimo e máximo atuais.

O brilho também mudará ligeiramente para mostrar os contornos da função em variação.

Valores próximos de zero são marcados com a cor azul escuro. O limite (de quão próximo de zero) pode mudar, mas valores com valor absoluto > 1 nunca são marcados.

A distribuição de cores entre o vermelho e o azul nem sempre permite ver facilmente como a função varia. Existe o modo “ondas”, que permite dividir a onda única vermelha e azul em várias ondas. Nesse modo, a cor não permitirá mais identificar onde estão o mínimo ou o máximo.

As variáveis não precisam ser necessariamente x e y. O editor analisará suas fórmulas e tentará encontrar exatamente duas variáveis sem definições; no entanto, x e y poderão ser assumidas como padrão caso sejam encontradas várias.

Coloração do domínio (funções complexas)

Há também um modo especial para quando você tem duas funções de duas variáveis. Nesse caso, uma “função principal” pode definir a distribuição de cores entre o vermelho e o azul, conforme explicado acima. Uma segunda função pode definir o brilho, do preto até a cor mais clara (coloração do domínio). Você pode definir a função principal clicando nela no canto inferior esquerdo.

Isso é usado principalmente para funções que retornam um número complexo.

z = x + i*y
f=(z*z-2)/(1-2*i-z)      ☑Gráfico

Essa função é dividida em duas partes: o argumento (ângulo) do número complexo calculado “f” e o valor absoluto. Há um botão no canto superior direito (coloração do domínio) que permite ativar ou desativar a alteração do brilho pela segunda função. Quando desativada, apenas a função principal selecionada é representada graficamente como uma única função.

Os botões que bloqueiam cores ou alternam para o modo de ondas serão aplicados à função principal atual. Se você quiser ajustar a distribuição do brilho, será necessário tornar temporariamente a segunda função como a principal; depois de ajustar a distribuição da cor conforme necessário, volte a definir essa função como secundária.

Se você quiser representar graficamente uma função de argumento complexo, o editor permite representar apenas essa única função. Como solução alternativa, você pode ajustar a fórmula e converter o número complexo em real (usando Re(z), Im(z), arg(z), |z|) e, então, representar graficamente qualquer número dessas funções.

Fractais

Para representar graficamente fractais, é necessária uma implementação rápida de uma função recursiva (uma maneira de construir uma sequência de valores a partir de um valor inicial). Isso pode ser feito com o uso da função recur. Abaixo está um exemplo de como representar graficamente o conjunto de Mandelbrot.

q = recur(0, z2rec+ x + iy, 10, 350)

|2-log2 (ln|q|)+irec |        ☑Gráfico

Todos os cálculos são realizados com números complexos.

0 é o primeiro valor inicial da sequência.

z2rec +x+iy  é a função recursiva propriamente dita que define o próximo valor da sequência. zrec é uma variável especial que representa o valor anterior da sequência. x e y são variáveis do gráfico.

10 é o raio de escape. A sequência é interrompida quando o módulo do valor é maior que o raio de escape. Você também pode especificar uma condição explícita, como zrec< 10.

350 é o número máximo de iterações (tamanho da sequência).

A função recur retorna o último valor zrec  (definido como q acima). irec  é um valor especial para obter o número de iterações.

Na função final representada graficamente, são utilizados logaritmos para obter uma distribuição de cores mais suave. Ela utiliza tanto o último valor (q) quanto o número de iterações (irec ). A referência a q deve estar sempre presente para que o gráfico funcione, mesmo que você precise apenas de irec .

Exemplo para o Conjunto de Julia

q=recur(x+iy, z2rec+0,4-0,6i, 10, 350)

Aqui, as variáveis do gráfico definem o valor inicial.

Coordenadas polares e equações paramétricas

Para exibir o gráfico de uma curva usando coordenadas polares, inclua duas equações com uma única variável:

r = u       ☑Gráfico
𝜑=20u    ☑Gráfico

r — distância do centro de coordenadas, 𝜑 — ângulo em radianos.

O procedimento é bastante semelhante para equações paramétricas:

x = u * sin(10u)     ☑Gráfico
y = u * cos(20u)     ☑Gráfico

As equações também podem ser combinadas em um sistema.

O intervalo de variação da variável é sempre de 0 a 1. Você pode adicionar fórmulas como u = 2πu₁, então u₁ se torna a variável, e u varia de 0 a 2π.

Gráfico 3D

Apenas para Android.

Você verá o botão “3D” à direita ao representar graficamente uma função de dois argumentos f(x,y), conforme descrito anteriormente (inicialmente, você vê a visualização acima no gráfico 3D e pode alterar a área XY). Quando o modo 3D é ativado, não é mais possível alterar a área XY; você só pode girar a câmera em torno do centro da superfície exibida.

Haverá um botão para ativar o modo de voo, no qual você pode alterar a posição e a orientação da câmera ajustando a velocidade e girando, como em um jogo.

Uma superfície representada pelas funções f(x,y) é chamada de superfície explícita.

Superfície paramétrica

Ao representar graficamente equações x=…, y=…, z=…, o gráfico 3D é aberto para uma superfície paramétrica. O intervalo de variação de cada variável é sempre de 0 a 1. É possível adicionar fórmulas como u=2πu₁; nesse caso, u₁ torna-se variável e u varia de 0 a 2π. Por exemplo:

x = v * sin(u)    ☑Gráfico
y = v * cos(u)    ☑Gráfico
z=vu               ☑Gráfico
v = 3v₁
u = 2πu₁

As equações podem ser combinadas em um sistema por conveniência, especialmente no caso de múltiplas superfícies.

Os nomes das variáveis podem ser diferentes: deve haver duas variáveis sem definições. No entanto, elas não podem ser x, y, z.

No caso comum, há duas variáveis; no caso de uma única variável, o gráfico será exibido como um túnel no espaço 3D (essencialmente uma curva).

Se você quiser representar graficamente uma superfície paramétrica, todas as funções adicionadas aos gráficos devem ser superfícies paramétricas.

Criação de mundos 3D

Apenas para Android.

O editor permite que você represente graficamente várias superfícies paramétricas, use suas imagens como texturas e altere muitos outros parâmetros para criar mundos 3D interessantes com o poder da matemática.

Uma única superfície é representada por um sistema com as equações x=, y=, z=. Você pode usar vários sistemas em uma única fórmula, combinando-os por meio da operação de soma.

Você também pode definir funções e usá-las:

Você só precisa representar graficamente a primeira. Cada função deve ter pelo menos um parâmetro, mesmo que você não precise dele.

Dentro do sistema, você pode adicionar vários parâmetros, como “resolução”, acima.

Observe que cada parâmetro é um único bloco de texto e está marcado como nome de variável (não como comentário). Digite as duas primeiras letras do nome (dentro do sistema) e um botão de contexto aparecerá para inseri-lo.

resolution

Define quantos pontos serão calculados (resolução * resolução) e quão suave será a superfície. Também define, em grande parte, a memória alocada e o tempo de computação. Se você tiver várias superfícies, deve sempre tentar reduzir esse parâmetro o máximo possível, mantendo, ainda assim, uma aparência aceitável.

Se o valor for 3 (mínimo permitido), você terá 9 pontos com valores dos parâmetros 0, 0,5, 1.

resolutionU e resolutionV também podem ser usados para definir resoluções diferentes para cada dimensão.

texture

Índice da imagem na tela. O índice 1 corresponderá à imagem maior (maior em termos da área como ela é realmente exibida na tela; você pode redimensioná-la facilmente). A imagem será desenhada para cobrir a superfície.

stretch

Define o quanto a textura deve ser esticada, ou seja, o tamanho que ela terá (em ambas as direções, preservando a proporção).

stretch2

Define o alongamento adicional em apenas uma direção. Isso alterará a proporção da textura.

stretchType

Valores 0 (padrão), 1, 2. Define o método de como a textura é desenhada. Se o resultado não ficar bom em alguns pontos, vale a pena tentar outros métodos.

textureRotate

Valores 0 (padrão) ou 1. O valor 1 fará com que a textura gire 90 graus. É como trocar os parâmetros da superfície (u->v, v->u) nas fórmulas.

brightness

Valores fracionários de -1 a 1. O padrão é 0. Altera o brilho da superfície quando a textura é usada.

color

Valor inteiro único no formato RGB (vermelho, verde, azul). 255 significa azul, 255*256 significa verde. É melhor usar a função “hex” e um valor hexadecimal; por exemplo, hex(ff0000) significa vermelho.

smooth

  • valor 0 — a superfície terá bordas distintas entre segmentos planos separados;
  • valor 1 (padrão) — as arestas serão menos visíveis, exceto no caso de grandes mudanças bruscas de ângulo (como no cubo);
  • valor 2 — todas as arestas ficam menos visíveis; até mesmo um cubo parecerá outra coisa

zOffset

Quando há várias superfícies no mesmo local (sobrepostas ou alinhadas de forma próxima), ocorre um conflito sobre qual deve ser desenhada por cima da outra. Podem ocorrer falhas durante o desenho. O valor -1 especifica que a superfície deve ser desenhada por cima. O valor 1 significa que ela deve ser desenhada por baixo. O valor padrão é 0. Você pode usar outros valores fracionários para definir a ordem, mas 1 ou -1 geralmente são suficientes.

background

O valor 0 (padrão) ou 1 significa que a superfície faz parte do fundo: céu, sol, lua (objetos distantes). Durante a exibição dessa superfície, a câmera fica sempre localizada no centro do sistema de coordenadas; mudar a posição não altera a aparência da superfície (seu tamanho).

lines

Valor 0 ou 1 (padrão). Define se as linhas de contorno devem ser exibidas sobre a superfície (quando não há textura).

transparency

Específico do jogo. Quando definido como 1, se for usada uma textura com áreas transparentes de alfa igual a 0, essas áreas permitem a passagem de objetos; caso contrário, elas funcionariam como uma borda invisível.

border

Específico do jogo. Se for 1, a superfície não é exibida, mas usada como uma borda invisível para objetos-alvo no jogo. Isso serve para controlar melhor para onde eles podem ir.

ignore

Específico do jogo. Se for 1, os objetos-alvo não sobrevoarão a superfície (não ficarão grudados nela). Caso contrário, como no comportamento padrão, eles tentarão permanecer mais próximos de alguma superfície por um certo período de tempo.

Existe uma opção para iniciar um jogo em qualquer gráfico 3D que você criar. O objetivo é perseguir e atirar em alvos que se movem ao longo das superfícies criadas.

Existem parâmetros globais que são aplicados ao jogo. Você pode adicioná-los na tela em qualquer lugar como uma equação independente.

Por exemplo:

positions

Define as posições iniciais permitidas do jogador e dos objetos-alvo. O valor é um sistema de equações semelhante ao da superfície 3D. Os objetos serão distribuídos aleatoriamente ao longo da superfície.

size

Tamanho do jogador e dos alvos. Quanto menor o tamanho, maior o mundo parecerá.

O valor padrão é 1, o que significa um tamanho padrão dependente do tamanho do mundo 3D. O valor = 0,5 significará metade do tamanho padrão. Um valor muito pequeno pode causar problemas com os gráficos.

Função f(x,y,z)

No caso da função das variáveis x, y, z, é exibido um 3D especial com pequenas partículas distribuídas pelo volume do espaço. Quanto maior o valor da função, maior a concentração de partículas. A cor das partículas também pode variar do azul (valor baixo) ao vermelho (valor alto).

 sin(x)+sin(y)+sin(z)     ☑Gráfico

Veja também abaixo sobre superfícies implícitas f(x,y,z) = 0.

Haverá vários parâmetros para ajustar o gráfico:

  • x₀, y₀, z₀, 𝚫xyz são usados para alterar a região do espaço;
  • “Res” é usado para alterar a resolução da malha 3D para calcular a função.
    Um valor mais alto significa melhor qualidade do gráfico e cálculo mais demorado;
  • “Den” é usado para limpar o espaço onde a função é pequena. Os valores variam de 0 a 1. Se a função varia de 0 a 10 e Den = 0,3, então apenas o intervalo de 3 a 10 exibirá partículas, enquanto o intervalo de 0 a 3 será um espaço vazio. Para superfícies implícitas, é melhor mantê-lo em 0; caso contrário, mantenha-o em um valor mais alto (cerca de 0,3).

Equações e curvas/superfícies implícitas

Ao representar graficamente uma equação com uma única variável f(x) = g(x), a parte direita é deslocada para a esquerda, exibindo o gráfico de f(x) – g(x). Os pontos de intersecção com o eixo dos eixos marcam a solução.

No gráfico de uma equação genérica com 2 ou 3 variáveis, por exemplo, f(x,y) = g(x,y), ela é convertida na inversa da diferença 1/|f(x,y) - g(x,y)|. O mesmo tipo de gráfico é exibido, assim como para as funções de duas variáveis descritas acima, mas no modo preto e branco. Um valor mais alto significa que a equação está mais próxima da igualdade. Se você observar curvas finas distintas, elas representam a solução da equação.

Com três variáveis, utiliza-se o mesmo princípio, mas com base no gráfico 3D de f(x, y, z) descrito acima.

Observe, no entanto, que y = x² é representado graficamente como x². Ela não é processada como uma equação, mas como a definição da função chamada y.

Desigualdades

As desigualdades são processadas como funções que produzem 0 ou 1 como resultado. Sistemas de desigualdades podem ser calculados e representados graficamente como uma conjunção (AND) de desigualdades. O modo preto e branco é ativado automaticamente quando há duas variáveis.

Sistemas de equações

O editor pode resolver sistemas de equações lineares.

Você não está restrito a usar apenas coeficientes numéricos. Se usar múltiplas variáveis, o editor assumirá que o número de variáveis reais é igual ao número de equações. As demais variáveis serão consideradas parte dos coeficientes. Você poderá ver várias soluções, dependendo das variáveis reais escolhidas. Funções como sin(x) também podem ser consideradas variáveis.

Você pode escrever um sistema na forma matricial e convertê-lo para a forma clássica e vice-versa.

Ao selecionar um sistema, você pode notar que aparece um botão de contexto com o mesmo sistema, mas com uma coluna adicional contendo condições. Ela é calculada como uma função por partes. A condição na última linha é opcional.

Matrizes

Com matrizes e vetores (caso particular de matriz), o editor realizará uma operação semelhante à realizada com números, exceto que, neste caso, ele não faz cálculos numéricos, mas sim transformações de expressões arbitrárias, produzindo uma única matriz de resultado. Se você definir uma variável como matriz, todas as outras fórmulas que a incluírem serão calculadas como matrizes. No entanto, em alguns casos, pode ser uma matriz de célula única. O editor exibe o tamanho da matriz calculada para cada fórmula.

Para uma matriz de uma única célula, ele pode, de fato, exibir um valor numérico.

Você também pode selecionar qualquer parte da fórmula, e o editor calculará a matriz se algumas variáveis forem matrizes.

Você pode obter o valor da célula da matriz usando um índice. Digite o nome da matriz em letras minúsculas e, em seguida, digite o índice com um valor numérico, por exemplo:

M=[4,5,3]
m₁ é 4

Se uma matriz tiver alguma dimensão com tamanho 1, o índice será aplicado a outra dimensão. Se ambas as dimensões forem maiores que um, o primeiro dígito do número será o índice da linha e o segundo dígito, o índice da coluna. Opcionalmente, pode-se usar uma vírgula entre os dois números.

É possível encontrar a matriz inversa ou elevar uma matriz a uma potência inteira.

Para usar a transposição, você pode adicionar o expoente “T” a uma variável, mas, para o rótulo da matriz, há um botão de contexto especial para fazer isso, que aparece quando você edita uma matriz.

Se você usar suas próprias funções, elas podem aceitar uma matriz como argumento ou retornar qualquer outra matriz com base nas expressões que você escrever. O comportamento será diferente quando você usar funções conhecidas, como sin, que funcionam apenas com argumentos numéricos. Essa função será aplicada a cada célula da matriz se você a passar como argumento; outra matriz com as mesmas dimensões será sempre retornada. O mesmo se aplica a todas as funções comuns que não podem processar matrizes como argumentos. Se você usar suas próprias funções, durante os cálculos matriciais elas serão todas expandidas, ou seja, substituídas por suas definições.

Se você precisar calcular o produto vetorial de dois vetores, use a função `cross`. O símbolo `cross` é usado como um separador opcional e geralmente é ignorado.

Cálculo

Para usar um diferencial (como dx), você deve usar a função com o nome “d” (digitar d seguido de x não será processado como um diferencial; o botão de contexto com a função aparece quando você digita a letra d). Quando você escreve um argumento simples como x, ele será exibido simplesmente como dx. Você também pode escrever qualquer expressão. Ao selecionar a função, o editor tentará encontrar a derivada da expressão do argumento.

Integrais

Ao digitar a letra “i”, você verá um botão de contexto de integral aparecer.

A capacidade do editor de resolver integrais é limitada. Se ele não conseguir encontrar uma solução, você não deve presumir que não exista nenhuma. Você pode facilmente enviar a expressão para a pesquisa do Google para encontrar uma solução online. Às vezes, pode haver várias soluções. Nesse caso, algumas delas podem nem sempre estar corretas: recomenda-se verificar uma solução usando uma integral definida e comparar o resultado do cálculo numérico direto com aquele baseado na solução.

Cada integral é, na verdade, uma função cujo nome é igual ao símbolo da integral. A função também possui parênteses que normalmente não são exibidos, a não ser quando você a edita. O editor espera encontrar um diferencial dentro de cada termo da expressão do argumento.

A posição dos limites para a integral definida pode ser alterada nas configurações: propriedade “Tg, ctg, etc. em vez de tan, cot, etc.”

Ao digitar uma integral indefinida, você também verá que um botão de contexto aparece para torná-la definida.

A expressão do argumento da integral também pode conter uma única integral aninhada juntamente com um diferencial (ou seja, uma integral dupla ou múltipla). Cada integral aninhada também deve conter um único diferencial entre parênteses.

∫(∫(x dx) dx)

Se você quiser calcular uma integral definida, todas as integrais aninhadas devem usar variáveis diferentes. Se você quiser resolver uma integral indefinida, todas as integrais aninhadas devem usar a mesma variável.

É possível representar graficamente integrais definidas. Defina o limite inferior como algum valor numérico e defina alguma variável como limite superior. Essa variável deve ser diferente da variável de integração. Ela será usada para o eixo x. Esse gráfico não é exato e pode não ser estável quando você altera a área do gráfico, especialmente na presença de singularidades. Isso dependerá do limite inferior e da área do gráfico.

Derivadas

Existem três maneiras de escrever (ou calcular) derivadas. A primeira é usar um diferencial, como mencionado anteriormente. A segunda maneira é colocar uma expressão entre parênteses, adicionar uma potência com o símbolo prime (semelhante ao apóstrofo) usando um botão de contexto que aparece após você pressionar o botão de potência/expoente (também o apóstrofo no teclado).

(x*sin(x))’

Não é necessário usar parênteses para uma única função ou variável. Derivadas de ordem superior também são suportadas.

A terceira maneira é usar a fração de dois diferenciais (notação de Leibniz).

Quando você digita um diferencial único como função d(), o editor exibe um botão de contexto com a fração. A terceira maneira é mais confiável quando você tem uma expressão com várias variáveis; caso contrário, não ficará claro qual variável deve ser usada para derivar.

Em equações diferenciais, você pode usar as duas últimas formas para denotar uma derivada. A terceira forma ainda é mais confiável para permitir que o editor compreenda melhor a tarefa.

O editor também conhece muitas fórmulas para resolver equações diferenciais, incluindo equações diferenciais lineares de segunda ordem. No entanto, em alguns casos, ele não sugerirá uma solução final, mas apenas o próximo passo possível. Talvez você precise definir a sequência correta de passos por conta própria.
