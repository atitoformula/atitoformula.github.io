O editor permite digitar fórmulas com dois propósitos: representação visual/impressão, juntamente com análise/cálculo de matemática real. Você pode usar fórmulas que podem ser calculadas ou resolvidas, com fórmulas que são apenas para exportação (LaTeX, imagem, etc.), incluindo texto comum. Suas fórmulas podem ser definições de variáveis ​​e funções, referenciando-se umas às outras, permitindo escrever programas simples que realizam cálculos numéricos.

O editor está disponível comoaplicativo Android e aplicativo web.

Edição básica

Observe que, em muitos casos, o editor não apenas insere um novo símbolo, mas corrige o que você digitou antes.

UMConforme você digita, muitos botões no painel principal mudam. Pressionar um botão repetidamente pode ajustar o que foi inserido anteriormente. Por exemplo, pressionar um botão de fração fará com que mais termos sejam incluídos no numerador. Para outros botões, basta verificar como eles mudam depois que você os pressiona uma vez.

Muitos botões adicionais aparecem à esquerda e à direita da tela conforme você digita. Eles são chamadosbotões de contexto. Por exemplo, quando você digita uma letra, aparece a lista de funções que começam com essa letra. Você também pode selecionar qualquer elemento,e os botões podem parecermudar isto.

Para digitar uma letra maiúscula, pressione e segure um botão.

Entre todas as fórmulas que você digitou, o editor está procurando por símbolos que são difíceis de digitar novamente: eles são adicionados no canto inferior direito para acesso rápido.

Usando comandos latex

Digite o nome completo de um símbolo (comando) no LaTeX e um botão aparecerá para inseri-lo.

Lista de símbolos e comandos suportados.

Você pode inserir qualquer símbolo digitando seu número hexadecimal Unicode. Por exemplo, digite "2295" e o botão de contexto com o símbolo ⊕ aparecerá. Você também pode combinar dois símbolos, por exemplo, digite u303. Primeiro, pressione o botão com o símbolo til (código 303), depois aparecerá um botão com o símbolo ũ, que combina u e til.

Exportar/Importar

Você pode exportar fórmulas em vários formatos.

  • Látex

Formato LaTeX bem conhecido para representação visual e impressão de fórmulas de alta qualidade. No entanto, não é confiável se você deseja restaurar fórmulas, pois não foi projetado para preservar exatamente o significado das fórmulas.

  • Texto de fórmulas (formato de texto curto)

O formato de texto representa o significado matemático da fórmula de forma resumida (mas não como ela se apresenta). Provavelmente será reconhecido por muitos outros aplicativos para tipos comuns de fórmulas. Corresponde à linguagem Matlab em muitos aspectos, mas nem sempre. Parte do que você digita pode não ser possível converter para este formato. Pode conter símbolos Unicode (não ASCII) quando usados.

  • Dados completos (json)

Permite restaurar todas as suas fórmulas exatamente como você as vê, incluindo alguns dados adicionais. Pode ser usado apenas com este editor. Não é muito adequado para visualização/edição manual. Baseado no formato JSON. No Android, arquivos (*.json) podem ser abertos de outros aplicativos (faz a importação).

  • PDF, Imagem (png)

Observe que as fórmulas podem ter uma aparência um pouco diferente daquela exibida no aplicativo. Durante a exportação, a qualidade da imagem pode ser alterada nas configurações. Durante a importação, a imagem é simplesmente adicionada como está: não há reconhecimento de fórmulas nela.

Se houvernenhuma seleçãoentão todas as fórmulas serão exportadas.

Quando você copia a seleçãoentão o editortambém faz a cópiapara o sistemaÁrea de transferência. Por padrão, usa o formato de texto. Nas configurações, pode ser alterado para latex.

No aplicativo web, você também pode copiar imagens de fórmulas selecionadas pressionando Ctrl+Shift+C. Para inserir da área de transferência do sistema (copiadas por outro aplicativo), use Ctrl+Shift+V. O formato das fórmulas será determinado automaticamente; caso contrário, serão inseridas como um bloco de texto normal.

Diferença entre Android e aplicativo web

O aplicativo Android geralmente tem mais recursos do que o aplicativo web.

Recursos do aplicativo Android não presentes no aplicativo web:

  • cálculos numéricos com alta precisão quando apenas operações aritméticas básicas são usadas
  • cálculo de algumas funções especiais
  • gráfico 3D
  • fonte de usuário personalizada para comentários

Somente o aplicativo web possui modo projetado para uso de teclado físico (desktop).

O aplicativo da Web será mais lento e consumirá mais bateria em dispositivos móveis em comparação ao aplicativo Android.

Uso do teclado

Em um dispositivo Android, você pode usar um teclado físico, bem como um aplicativo web.

Ao executar o aplicativo web em um PC/laptop, a interface do usuário é ajustada automaticamente para o uso do teclado. Se você realizar alguma ação sem o teclado, uma nota poderá aparecer na parte superior da tela com o atalho de teclado para essa ação.

No aplicativo para Android, há uma configuração para habilitar o modo com o uso do teclado físico. Será semelhante ao aplicativo para desktop.

Você pode pressionar um botão de contexto (no lado esquerdo) pressionando a tecla Espaço várias vezes enquanto segura a tecla Ctrl. Você pode pressionar um botão de sugestão (no lado direito) pressionando a tecla Espaço várias vezes enquanto segura a tecla Ctrl e a tecla Shift. O mesmo vale para letras digitadas recentemente no canto inferior direito (quando as sugestões não são exibidas).

Funções

Se você digitar algumas letras seguidas de parênteses, isso não significará uma chamada de função(embora pareça semelhante). Digite a primeira letra do nome da função ou o nome completo, um botão de contexto aparecerá parainsira a função chamar. Para funções bem conhecidas, o editor pode corrigi-lo automaticamentedepois de digitar o nome da função seguido de parênteses.FAs chamadas de função serão exibidas de forma diferente de quando você apenas digita várias variáveis ​​seguidas de parênteses.Abaixo eles serão chamados simplesmente de funções.

O editor pode não exibir parênteses em alguns casos, mas eles aparecem quando você posiciona o cursor dentro ou depois da função. Se quiser que os parênteses sejam sempre exibidos, selecione a função com o argumento. Um botão de contexto aparecerá com a mesma função, com a configuração que a faz sempre exibir parênteses.

Não é possível editar o nome de uma função. Isso pode ser inconveniente se a expressão do argumento for grande. Nesse caso, basta selecionar a função e você verá um botão para copiar apenas o argumento. Clique nele, digite uma nova função e cole o argumento.

Para usar suas próprias funções, basta digitar uma letra seguida de parênteses. Um botão aparecerá para substituí-la por uma chamada de função que terá essa única letra em seu nome. Para criar uma função com um nome mais longo, selecione algumas letras com parênteses vazios após elas. Observe que funções com uma única letra podem ser exibidas de forma diferente em comparação com funções com várias letras..

Para definir uma função, crie uma fórmula que tenha essa função chamada com argumentos de uma única letra, seguidos por "igual" e uma expressão que faça referência a esses argumentos.

f(x)=x*x
f(x,y)=x*y

Onde quer que você use essa função, ela pode ser calculada ou facilmente substituída por sua definição, se necessário.

Arraste e solte

Você pode alterar facilmente a ordem dos multiplicadores ou termos. Basta selecionar um ou mais e arrastar e soltar a seleção para um novo local. Isso também funciona com frações: você pode mover elementos para dentro e para fora de uma fração, para outra. Também funciona com equações que contêm frações: você pode mover elementos da parte esquerda da equação para a direita e vice-versa. O editor permitirá apenas os movimentos que são matematicamente corretos.

Ao selecionar uma parte da fórmula, você poderá ver um “EBotão "extract". É prático e permite mover facilmente a seleção para uma nova fórmula, que será a definição de uma nova variável. Basta digitar o nome da variável e ela será inserida no lugar da seleção. Isso facilita a divisão de fórmulas grandes em menores, referenciando-as umas às outras por meio dos nomes das variáveis.

Adicionando texto usual

Você pode inserir blocos de texto para usar variáveis ​​com nomes longos ou para escrever comentários. O botão "Texto" permite fazer isso. Ele aparece quando você cria uma nova fórmula (ou você digita ‘t’.). Outro botão está abaixo no painel principal.

Uma caixa de diálogo será exibida para editar o texto e haverá uma opção para escolher se deseja ignorar esse texto em matemática como comentário ou processá-lo como variável.

Depois você pode clicar duas vezes para editar o texto.

Quando o texto for grande, um botão vertical aparecerá à direita para permitir que você altere a largura do bloco de texto.No canto superior direito do texto também há um botão para alterar o alinhamento.

Quando você digita variáveis ​​(a maioria dos símbolos), cada uma vai para um bloco de texto separado; apenas os dígitos são automaticamente combinados em um único bloco: número. O estilo itálico é aplicado a variáveis ​​de uma única letra por padrão, mas não a blocos de texto maiores.Quando você digita (ou seleciona) váriossímbolosentão um botão de contexto também aparece paracombine-os em um único bloco de texto, e ele será processado como uma única variável com nome longo (se não houver espaços, etc.). Formatando issoitálico ou negrito é aplicado a todo o bloco de texto.

Nas configurações do aplicativo Android, você pode carregar uma fonte personalizada (de https://fonts.google.com/), que será usada apenas para comentários. Esta opção não está disponível em todos os dispositivos, pois requer os serviços do Google.

Desenho

O editor também suporta desenho, implementando diversos recursos de um editor de gráficos vetoriais. Habilite-o nas configurações. É possível desenhar qualquer forma, aplicar cores, alterar os pontos da forma, agrupar e alterar a ordem z. Veja os guias em vídeo.

Análise e transformação de expressões

Quando você seleciona qualquer parte da fórmula,o editoriniciará a busca entre todas as fórmulas da biblioteca incorporada que podem ser aplicadas à expressão selecionada. Listará todas as outras expressões possíveis que podem seguir a original com base em regras matemáticas. Também inclui soluções para problemas matemáticos clássicos.complexo cálculos será iniciado somente após você selecionar uma expressão específica.

A lista de sugestões pode ser muito longa, mas as melhores geralmente aparecem entre as primeiras. Uma sugestão pode ter um botão que permite ver informações mais detalhadas sobre a fórmula da biblioteca utilizada.

Quando o editor não consegue encontrar uma solução, há um botão no canto superior direito para iniciar a pesquisa no Google.

Quando você clicasobre sugestão, então, por padrão, ela será inserida substituindo a expressão selecionada. Um botão aparecerá permitindo reverter a ação anterior, duplicar a fórmula original onde a seleção estava e, em seguida, fazer a substituição na nova fórmula, mantendo a antiga. Ou também é possível anexar a expressão sugerida à selecionada.depois dos iguais sinal.

Selecione um únicovariável e o editor irá sugerir mais operações relacionadas a ela: substituição, resolução de equação, etc. A fórmula inteira será transformada neste caso.

Números complexos

Para fazer cálculos com números complexos, basta incluir o símbolo i nas suas fórmulas. Ele pode ser desativado nas configurações. Existem funções que permitem obter a parte imaginária e real de um número complexo, além de argumentos e módulos (Re(z),Im(z),arg(z),|z|).

Usar conjfunção para conjugado complexo.

Trigonometria

Todos os cálculos de funções trigonométricas são realizados em radianos. O símbolo de grau ° é processado como uma conversão para radianos x / 180 * π, por exemplo, 45° será 0,7853…

Para digitar um símbolo de grau para qualquer número, primeiro pressione o botão liga/desliga e, em seguida, o botão de contexto com o grau aparecerá.

é processado como 1/sin, não como função trigonométrica inversa. Usearco senopara isso.

Gráficos

Durante cálculos ou gráficos, o editor examina todas as suas fórmulas para ver como elas se referenciam. Por exemplo:

r*c
r=sen(x)
c=cos(x)

Se houver definições duplicadas para uma variável, um ponto de exclamação será exibido.

Para ver os gráficos, primeiro você precisa escolher as fórmulas que serão incluídas. Ao editar uma fórmula, há um botão à esquerda para incluí-la nos gráficos. Após selecionar pelo menos uma fórmula, pressione o botão no canto superior esquerdo para exibir os gráficos. Se a fórmula tiver um sinal de igual, a expressão à esquerda deve ser um nome de variável simples ou função como f(x). No entanto, você pode representar graficamente quaisquer desigualdades que produzam valores 0 ou 1.

Observe que, se você selecionar uma única variável em uma fórmula, o editor tentará resolver e construir a expressão para essa variável. Ele também permitirá que vocêveja ográficodo produzidofunção.

TO editor começará a analisar todas as fórmulas que você incluiu no gráfico, recursivamenteescaneando através detodas as fórmulas que definem variáveis ​​usadas nas fórmulas iniciais que você incluiu.

Ao construir um gráfico comum, o editor espera encontrar uma única variável que não tenha fórmula. Ela se tornará uma variável para o eixo x. Outras variáveis ​​para as quais você deve definir alguns valores numéricos se tornarão parâmetros.

Dependendo das configurações, a variável "x" pode ser assumida como padrão. As demais variáveis ​​se tornarão parâmetros automaticamente com valores padrão iniciais.

Quando o gráfico éabertoPara cada parâmetro, haverá um botão na parte superior. Pressione-o para começar a alterar o valor do parâmetro usando um controle deslizante. Há dois botões que permitem alterar o intervalo de valores usado pelo controle deslizante. Se precisar definir um valor exato, defina-o.na fórmula para esse parâmetro.

Gráficos de funções com duas variáveis ​​(funções complexas)

O editor também permite analisar funções com duas variáveis. Ele desenha um tipo de gráfico colorido que geralmente é usado para analisar funções de números complexos (representados por dois números reais). Mas você pode usá-lo para qualquer tipo de função com duas variáveis. Por exemplo:

sen(x)+sen(y)

Neste tipo de gráfico, o valor da função é representado por uma cor. O valor vermelho corresponde ao valor máximo da função, o valor azul ao valor mínimo. Cada variável corresponde a um eixo.

Os valores mínimo e máximo são calculados apenas dentro da área exibida. Ao mover para outra área, esses valores podem mudar significativamente, mas sempre haverá uma distribuição de cores entre vermelho e azul. A correspondência entre o valor da função e a cor não é fixa inicialmente. Pode ser necessário primeiroencontre uma áreaque produz valores mínimos e máximos adequados (nãosingularidade nele), então pressione o botão superior direito “Cores bloqueadas”, que fixará as cores, lembrando os valores mínimos e máximos atuais.

A distribuição de cores entre vermelho e azul nem sempre permite que você veja facilmente como a função muda. Existe o modo de ondas que permite dividir a única onda vermelha e azul em várias. Neste modo, a cor não permitirá mais que você veja onde está o mínimo ou o máximo.

Há também um modo especial quando você tem duas funções de duas variáveis. Neste caso, uma função principal definirá a distribuição de cores entre vermelho e azul, conforme explicado acima. Outra segunda função definirá o brilho do preto até a cor mais brilhante. Você pode definir a função principal clicando nela no canto inferior esquerdo.

Este modo é habilitado por padrão quando você tem uma função de número complexo.Por exemplo

z=x+i*y
f=(z*z-2)/(1-2*i-z)

Somente a fórmula para “f” deve ser incluída nos gráficos.Neste caso a função principal será o argumento do número complexo calculado“f”e o valor absoluto definirá o brilho. Há um botão no canto superior direito que permite ativar ou desativar a alteração de brilho pela segunda função.

Botões quetrancar cores ou mudançaseO modo Waves será aplicado à função principal atual. Se você quiser ajustar a distribuição de brilho, precisará tornar a segunda função a principal temporariamente. Após ajustar a distribuição de cores conforme necessário, torne esta função a segunda novamente.

Se você quiser representar graficamente uma função de argumento complexo,o O editor permite que você represente graficamente apenas esta função. Como solução alternativa,eVocê pode ajustar a fórmula e converter um número complexo em um real (usando Re(z),Im(z),arg(z),|z|) e então representar graficamente qualquer número dessas funções.

gráfico 3D

A partir da versão 1.1.6. Somente para Android.

Você verá o botão de gráfico "3D" à direita ao representar graficamente uma função de duas variáveis, como descrito anteriormente (inicialmente, você verá a visualização acima no gráfico 3D e poderá alterar a área XY). Quando o 3D estiver aberto, não será mais possível alterar a área XY, você só poderá girar a câmera em torno do centro da superfície exibida.

Haverá um botão para ativar o modo de voo, quando você poderá alterar a posição e a orientação da câmera alterando a velocidade e girando como em um jogo.

Uma superfície representada por funções f(x,y) é chamada de superfície explícita.

Superfície paramétrica

Ao representar graficamente as equações x=…, y=…, z=…, o gráfico 3D é aberto para superfícies paramétricas. O intervalo de variação para cada variável (parâmetro) é sempre de 0 a 1. Você pode adicionar fórmulas como u=2πu₁, então u₁ se torna variável e u vai de 0 a 2π. Por exemplo:

x=v*sin(u)
y=v*cos(u)
z=de
v=3v₁
u=2πu₁

As equações podem ser combinadas em um sistema para maior conveniência, especialmente no caso de múltiplas superfícies.

Os nomes dos parâmetros podem ser diferentes: deve haver 2 variáveis ​​sem definições que se tornem parâmetros. No entanto, elas não podem ser x, y, z.

No caso usual, há dois parâmetros (variáveis); no caso de apenas um, o gráfico será exibido como um túnel no espaço 3D.

Se você quiser representar graficamente uma superfície paramétrica, cada função adicionada aos gráficos deve ser uma superfície paramétrica.

Criando mundos 3D

A partir da versão 1.2.2. Somente para Android.

O editor permite que você crie gráficos de diversas superfícies paramétricas, use suas imagens como texturas e altere muitos outros parâmetros para criar mundos 3D interessantes com o poder da matemática.

Uma única superfície é representada por um sistema de equações com equações x=, y=, z=. Você pode escrever múltiplos sistemas em uma única fórmula usando a operação de soma.

Você também pode usar funções de soma

Ele criará 12 superfícies com posições diferentes.

Você também pode definir funções e usá-las:

É necessário representar graficamente apenas o de cima. Cada função deve ter pelo menos um parâmetro, mesmo que você não precise dele.

Dentro do sistema você pode adicionar vários parâmetros como “resolution” acima.

Observe que cada parâmetro é um único bloco de texto e marcado como nome da variável (não comentário).Digite as duas primeiras letras do nome (dentro do sistema) e o botão de contexto aparecerá para inseri-lo.

resolution

Define quantos pontos serão calculados (resolução * resolução) e quão lisa será a superfície. Também define em grande parte a memória alocada e o tempo de computação.Se você tiver várias superfícies, você deve sempre tentar reduzir esse parâmetro o máximo possível, mantendo ainda uma aparência aceitável.

Se o valor for 3 (mínimo permitido), você terá 9 pontos com valores dos parâmetros 0, 0,5, 1.

texture

Índice da imagem na tela. O índice 1 corresponderá à maior imagem (a maior em termos da área em que é exibida na tela, você pode redimensioná-la facilmente). A imagem será desenhada para cobrir a superfície.

stretch

Define o quanto esticar a textura, quão grande ela ficará (em ambas as direções, preservando a proporção).

stretch2

Define alongamento adicional em apenas uma direção. Isso altera a proporção da textura.

stretchType

Valores 0 (padrão), 1, 2. Define o método de como a textura é desenhada. Se não ficar bonito em alguns pontos, faz sentido tentar outros métodos.

textureRotate

Valores 0 (padrão) ou 1. O valor 1 fará com que a textura gire 90 graus. É como trocar os parâmetros de superfície (u->v, v->u) em fórmulas.

brightness

Valores fracionários de -1 a 1. O padrão é 0. Altera o brilho da superfície quando a textura é usada.

color

Valor inteiro único no formato RGB (vermelho, verde, azul). 255 significa azul, 255*256 significa verde. É melhor usar a função "hex" e um valor hexadecimal, por exemplo, hex(ff0000) significa vermelho.

smooth

  • valor 0 - a superfície terá bordas distintas entre segmentos planos separados;
  • valor 1 (padrão) - as bordas serão menos visíveis, exceto em caso de grande mudança repentina de ângulo (como no caso do cubo);
  • valor 2 - todas as arestas são menos visíveis, até mesmo o cubo parecerá outra coisa

zOffset

Quando você tem várias superfícies em um só lugar (muito sobrepostas/combinadas), isso gera um conflito sobre o que desenhar em cima da outra. Pode haver falhas durante o desenho. O valor -1 especifica que a superfície deve ser desenhada por cima. O valor 1 significa desenhar atrás. O valor padrão é 0. Você pode usar outros valores fracionários para definir a ordem, mas 1 ou -1 geralmente são suficientes.

background

Valor 0 (padrão) ou 1, que significa que a superfície faz parte do plano de fundo: céu, sol, lua (objetos distantes). Durante a exibição de tal superfície, a câmera está sempre localizada no centro das coordenadas; mudar de posição não altera a aparência da superfície (seu tamanho).

lines

Valor 0 ou 1 (padrão). Define o clima para exibir linhas de contorno sobre a superfície (quando não há textura).

Existem parâmetros globais que são aplicados a gráficos ou jogos 3D.

Você pode adicioná-los na tela em qualquer lugar como uma equação independente.

Por exemplo

positions

Define as posições iniciais permitidas para o jogador e os objetos alvo. O valor é um sistema de equações, como para uma superfície 3D. Os objetos serão distribuídos aleatoriamente pela superfície.

size

Tamanho do jogador e dos alvos. Quanto menor o tamanho, maior o mundo parecerá.

O valor padrão é 1, o que significa um tamanho padrão dependendo do tamanho do mundo 3D. Valor = 0,5 significa metade do tamanho padrão. Um valor muito baixo pode causar problemas com os gráficos.

Sistemas de equações

O editor pode resolver sistemas de equações lineares.

Você não está restrito a usar apenas coeficientes numéricos. Se usar múltiplas variáveis, o editor assumirá que o número de variáveis ​​reais é igual ao número de equações. O restante das variáveis ​​será considerado parte dos coeficientes. Você poderá ver diversas soluções, dependendo das variáveis ​​reais escolhidas.Funções como sin(x) também podem ser consideradas variáveis.

Você pode escrever um sistema em forma matricial e convertê-lo para a forma clássica e vice-versa.

Ao selecionar um sistema, você poderá notar que um botão de contexto aparece com o mesmo sistema, mas com uma coluna adicional com condições. Esses sistemas são úteis durante cálculos. A condição na última linha é opcional.

Matrizes

Com matrizes e vetores (caso particular de matriz), o editor realizará uma operação semelhante à dos números, exceto que, neste caso, não realizará cálculos numéricos, mas transformações de expressões arbitrárias, produzindo uma única matriz resultante. Se você definir uma variávelcomo matrizentão todas as outras fórmulas que a incluem serão calculadas como matrizes. No entanto, em alguns casos, pode ser uma matriz de célula única. O editor exibe o tamanho da matriz calculada para cada fórmula.

Para uma única matriz de células, ele pode realmente exibir númerosvalor.

Você também pode selecionar qualquer partede fórmulae o editor calculará a matriz se algumas variáveis ​​forem matrizes.

Você podeobtenha o valorda matrizcélula usando um índice. Digite o nome da matriz em letras minúsculas e, em seguida, digite o índicecom valor numérico, por exemplo

M=[4,5,3]
m₁ é 4

Se a matriz temalgunsdimensão com tamanho 1, o índice será aplicado a outra dimensão. Se ambas as dimensões forem maiores que um, o primeiro dígitodo númeroserá o índice da linha e o segundo dígito, o índice da coluna. Opcionalmente, pode-se usar vírgula entre dois números.

É possível obter uma matriz inversa ou elevar uma matriz a uma potência inteira.

Para usar a transposição, você pode adicionar a potência “T” a uma variável, mas para o rótulo da matriz há um botão de contexto especial para fazer isso, que aparece quando você edita uma matriz.

Se você usar suas próprias funções, elas podemaceitar uma matrizcomo argumento ou retornar qualquer outra matriz com base nas expressões que você escrever. Será diferente quando você usar funções conhecidas comopecadoque funciona apenas com argumentos numéricos. Esta função será aplicada a cada célula da matriz. Se você a passar como argumento, outra matriz com as mesmas dimensões sempre será retornada. O mesmo se aplica a todas as funções comuns que não podem processar matrizes como argumento.Se você usar suas próprias funções, durante os cálculos de matriz todas elas serão expandidas, ou seja, substituídas por suas definições.

Se você precisar calcular o produto vetorial de dois vetores, usecruzar função. O símbolo de cruz é usado como separador opcional e geralmente ignorado.

Cálculo

Para usar differencial (como dx), você deve usar a função com o nome "d" (digitar d seguido de x não será processado como diferencial; o botão de contexto com a função aparece quando você digita a letra d). Quando você escreve um argumento simples como x, ele será exibido simplesmente como dx. Você também pode escrever qualquer expressão. Ao selecionar a funçãoção, o editor tentará encontrar a derivada para a expressão do argumento.

Integrais

Ao digitar a letra “i”, você verá um botão de contexto integral aparecer.

A capacidade do editor de resolver integrais é limitada. Se ele não encontrar uma solução, você não deve presumir que não há solução. Você pode facilmente usar a busca do Google para encontrar uma solução online. Às vezes, pode haver várias soluções. Neste casoalgumas delas podem não estar sempre corretas: é recomendado verificar uma solução usando integral definida e comparar o resultado do cálculo numérico direto com aquele baseado na solução.

Cada integral é, na verdade, uma função cujo nome é igual ao símbolo da integral. A função também possui parênteses que geralmente não são exibidos, apenasequando você o edita. O editor espera encontrar um diferencial dentro de cada termo da expressão.

A posição dos limites para integral definida pode ser alterada nas configurações: propriedade “Tg, ctg, etc. em vez de tan, cot, etc.”

Ao digitar uma integral indefinida, você também verá que um botão de contexto aparece para torná-la definida.

A expressão de argumento integral também pode conter outra integral junto com a diferencial (ou seja, integral dupla ou múltipla). Cada integral aninhada também deve conter uma única diferencial entre parênteses.

Se você quiser calcular uma integral definida, todas as integrais aninhadas devem usar variáveis ​​diferentes. Se você quiser resolver uma integral indefinida, todas as integrais aninhadas devem usar a mesma variável.

Você pode representar graficamente integrais definidas. Defina o limite inferior para algum valor numérico e defina uma variável como limite superior. Essa variável deve ser diferente da variável de integração. Ela será usada para o eixo x. Esse gráfico não é exato e pode não ser estável quando você altera a área do gráfico, especialmente na presença de singularidade. Dependerá do limite inferior e da área do gráfico.

Derivativos

Existem três maneiras de escrever (ou encontrar) a derivada. A primeira é usar a diferencial, como mencionado anteriormente. A segunda maneira é colocar uma expressão entre parênteses e adicionar potência.com símbolo primo (semelhante ao apóstrofo) usando um botão de contexto que aparece depois de pressionar o botão liga/desliga/expoente (tambémapóstrofo no teclado).

(x*sin(x))’

Parênteses não são necessários para uma única função ou variável. Derivadas de ordem superior também são suportadas.

A terceira maneira é usar a fração de dois diferenciais (notação de Leibniz).

Ao digitar um único diferencial d(), o editor exibe um botão de contexto com a fração. A terceira maneira é mais confiável quando se tem uma expressão com múltiplas variáveis; caso contrário, não ficará claro qual variável deve ser usada para diferenciar.

Se você precisar aumentar a ordem da derivada, isso pode ser feito com os botões de contexto que aparecem ao selecionar a derivada de primeira ordem. Você não podete que o editor usa um especialvisual bbloqueio para derivadas de ordem superior e é restrito como você pode editá-lo.

Em equações diferenciais, você pode usar as duas últimas maneiras de denotar a derivada. A terceira maneira é ainda mais confiável para permitir que o editor entenda melhor a tarefa.
